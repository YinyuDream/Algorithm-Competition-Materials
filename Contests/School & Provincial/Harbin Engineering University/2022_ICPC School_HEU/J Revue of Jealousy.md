# Revue of Jealousy

## 题目描述

一年一度的圣翔祭终于开赛了！

本次圣翔祭实行**单败淘汰赛**的赛制，$2^n$ 位舞台少女将进行 $n$ 轮的淘汰赛，每轮比赛都有一半的舞台少女被淘汰。最终赢下比赛的舞台少女将成为「Top Star」。

每轮淘汰赛中，第 $1$ 个人将与第 $2$ 个人对决，第 $3$ 个人将与第 $4$ 个人对决，以此类推。剩下的赢家将按原先的顺序继续进行淘汰赛，直到决出冠军。

每位舞台少女拥有自己的**闪耀值** $a_i$。一场比赛结果仅由双方的**闪耀值**决定：

- 当双方闪耀值**不相等**时，闪耀值**更高**的一方将胜出。
- 当双方闪耀值**相等时**，双方各有 $1/2$ 的概率胜出。

作为舞台少女中的一员，Tsuyuzaki Mahiru 想知道每位舞台少女成为「Top Star」的概率。于是她找到了你，希望你回答这个问题。

## 输入描述

输入数据共两行。

第一行一个整数 $n$ $(1 \leq n \leq 18)$，代表舞台少女的数量为 $2^n$。

第二行共 $2^n$ 个整数 $a_1,a_2,...,a_{2^n}$，代表第 $i$ 个舞台少女的闪耀值为 $a_i$ $(1 \leq a_i \leq 10^9)$。

## 输出描述

输出共 $2^n$ 行。

每行输出一个最简分数 $x/y$ ($x,y$ 均以非负整数表示)。

其中第 $i$ 行的最简分数代表第 $i$ 个舞台少女成为「Top Star」的概率 $p_i$。

如果某个舞台少女不可能成为「Top Star」，那么输出 "0/1"（不含引号）。

## 示例1

### 输入

```
1
1 1
```

### 输出

```
1/2
1/2
```

## 示例2

### 输入

```
2
4 5 1 4
```

### 输出

```
0/1
1/1
0/1
0/1
```

## 示例3

### 输入

```
2
1 9 1 9
```

### 输出

```
0/1
1/2
0/1
1/2
```

## 示例4

### 输入

```
2
2 3 3 3
```

### 输出

```
0/1
1/2
1/4
1/4
```
