# Digital Demonstration

## 题目描述

Tadokoro Kouji 喜欢 $114514$。

Tadokoro Kouji 手中有一个正整数 $n$，她可以对 $n$ 进行不超过 $200000$ 次如下操作：

- 将 $n$ 拆分为两个满足 $a+b=n$ 的**正整数** $a,b$ $(1 \leq a,b \leq 10^7)$，并将 $a \times b$ 赋值给 $n$。

现在 Tadokoro Kouji 想将 $n$ 变为 $114514$。于是她找到了你，希望你解决这个问题。

## 输入描述

一行一个正整数 $n$ $(1 \leq n \leq 114514)$，表示 Tadokoro Kouji 手中的正整数 $n$。

## 输出描述

如果这样的方案不存在，则输出一行一个 $-1$。

否则在第一行输出一个整数 $T$ $(0 \leq T \leq 200000)$，表示你的操作次数。

接下来 $T$ 行，每行输出两个正整数 $a,b$ $(1 \leq a,b \leq 10^7)$，表示每次操作中拆分的正整数 $a,b$。

## 示例

### 示例1

#### 输入
```plain
1
```

#### 输出
```plain
-1
```

### 示例2

#### 输入
```plain
106
```

#### 输出
```plain
2
23 83
62 1847
```

#### 说明

在第一次操作中，我们将 $106$ 拆分成 $23$ 和 $83$，并将 $n$ 赋值为 $23 \times 83 = 1909$。

在第二次操作中，我们将 $1909$ 拆分成 $62$ 和 $1847$，并将 $n$ 赋值为 $62 \times 1847 = 114514$。

### 示例3

#### 输入
```plain
114514
```

#### 输出
```plain
0
```
