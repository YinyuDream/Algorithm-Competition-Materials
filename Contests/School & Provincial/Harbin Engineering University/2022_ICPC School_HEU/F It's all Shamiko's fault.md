# It's all Shamiko's fault

## 题目描述

魔法少女 Chiyoda Momo 和 Hinatsuki Mikan 正在帮助魔族 Shamiko 解除诅咒！

为了解除诅咒，Chiyoda Momo 需要用到姐姐留下的许愿卡。许愿卡共有 $n$ 种，每种许愿卡有「黑色」和「白色」两种类型，其中「黑色」的第 $i$ 种许愿卡的价值为 $a_i$，而「白色」的第 $i$ 种许愿卡的价值为 $b_i$。

同颜色的许愿卡拥有增幅效果。如果 Chiyoda Momo 选择了 $m$ 张同颜色的许愿卡，那么每张同颜色的许愿卡的价值将会乘以 $m$。

现在 Chiyoda Momo 需要从 $n$ 种许愿卡中各选择 $1$ 张。她希望她的选择使得许愿卡的价值和**最大**。于是她找到了你，希望你解决这个问题。

## 输入描述

本题有多组数据。

第一行一个正整数 $T$ $(T \leq 400)$，表示数据组数。

对于每组数据：

第一行三个正整数 $n$ $(1 \leq n \leq 400)$，代表许愿卡的种数为 $n$。

第二行共 $n$ 个整数 $a_1,a_2,...,a_n$，代表「黑色」的第 $i$ 种许愿卡的价值为 $a_i$ $(1 \leq a_i \leq 10000)$。

第三行共 $n$ 个整数 $b_1,b_2,...,b_n$，代表「白色」的第 $i$ 种许愿卡的价值为 $b_i$ $(1 \leq b_i \leq 10000)$。

输入数据保证 $\sum n \leq 400$。

## 输出描述

对于每组询问，输出一行一个正整数，表示 Chiyoda Momo 能够获得的最大价值和。

## 示例

### 示例输入

```
2
3
1 1 4
5 1 4
2
1 9
9 1
```

### 示例输出

```
30
20
```
