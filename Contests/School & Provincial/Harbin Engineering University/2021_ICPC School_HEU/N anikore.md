The 16th Harbin Engineering University Collegiate Programming Contest will be held in April 25, 2021.

If 2021 is a prime, output **Yes**; otherwise, output **No**.

You can print each letter in any case (upper or lower). For example, **nO** will be also considered a correct answer if **No** is a correct answer.

Recall that a prime is a natural number greater than 1 that is not a product of two smaller natural numbers. For example, 5 is prime because the only ways of writing it as a product, $1 \times 5$ or $5 \times 1$, involve 5 itself. However, 4 is not prime because it is a product $2 \times 2$ in which both numbers are smaller than 4.

## 输入描述

```
No input.
```

## 输出描述

```
Output Yes or No.

You can print each letter in any case (upper or lower). For example, nO will be also considered a correct answer if No is a correct answer.
```
