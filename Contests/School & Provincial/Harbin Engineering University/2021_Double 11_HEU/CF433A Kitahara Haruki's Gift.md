# CF433A Kitahara Haruki's Gift

## 题目描述

北原春希为冬马和纱和小木曾雪菜买了 $n$ 个苹果。现在他想要把所有苹果分给两个朋友。

每个苹果的重量为 $100$ 克或 $200$ 克。当然，北原春希不想让任何一个朋友不开心。因此，分给冬马和纱的苹果的总重量必须等于分给小木曾雪菜的苹果的总重量。

但是很不巧，北原春希现在没有刀，因此不能把任何一个苹果切开。请你告诉他，是否有可能把所有苹果公平地分给两个朋友？

## 输入格式

第一行包含一个整数 $n$ $(1 \leq n \leq 100)$，表示苹果的数量。第二行包含 $n$ 个整数 $w_1, w_2, \ldots, w_n$（$w_i = 100$ 或 $w_i = 200$），其中 $w_i$ 表示第 $i$ 个苹果的重量。

## 输出格式

输出一行，如果可以将所有苹果公平分给两个朋友，输出 YES（不带引号）；否则输出 NO（不带引号）。

## 输入输出样例 #1

### 输入 #1

```
3
100 200 100

```

### 输出 #1

```
YES

```

## 输入输出样例 #2

### 输入 #2

```
4
100 100 100 200

```

### 输出 #2

```
NO

```

## 说明/提示

在第一个测试样例中，北原春希可以把第一个和最后一个苹果给小木曾雪菜，把中间的苹果给冬马和纱。
