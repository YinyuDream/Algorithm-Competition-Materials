# T290949 Jxt的流量管理

## 题目描述

为了能够在网上冲浪，Jxt 购买了一个数据套餐：

- 每月他将获得 $x \rm{MB}$ 流量。
- 每月未用完的流量，可以在次月继续使用。

现在，我们知道了 Jxt 在使用这个套餐的前 $n$ 个月中，每月使用了多少 $\rm{MB}$ 流量。请你帮忙计算，第 $n+1$ 月他能使用多少 $\rm{MB}$ 流量。

## 输入格式

第一行一个整数 $x$。

第二行一个整数 $n$。

接下来 $n$ 行，每行一个整数 $p_i$，表示第 $i$ 月 Jxt 使用了多少 $\rm{MB}$ 流量。

## 输出格式

一行，一个整数，表示第 $n+1$ 月 Jxt 能使用多少 $\rm{MB}$ 流量。

## 输入输出样例 #1

### 输入 #1

```
10
3
4
6
2 
```

### 输出 #1

```
28
```

## 输入输出样例 #2

### 输入 #2

```
10
3
10
2
12 
```

### 输出 #2

```
16
```

## 输入输出样例 #3

### 输入 #3

```
15
3
15
10
20 
```

### 输出 #3

```
15
```

## 说明/提示

#### 样例 1 解释

第一月，Jxt 能使用 $10\rm{MB}$ 流量，实际使用 $4\rm{MB}$ 流量，剩余 $6\rm{MB}$ 流量。 

第二月，Jxt 能使用 $6+10=16(\rm{MB})$ 流量，实际使用 $6\rm{MB}$ 流量，剩余 $10\rm{MB}$ 流量。 

第三月，Jxt 能使用 $10+10=20(\rm{MB})$ 流量，实际使用 $2\rm{MB}$ 流量，剩余 $18\rm{MB}$ 流量。
 
第四月，Jxt 能使用 $18+10=28(\rm{MB)}$ 流量。

---

#### 数据规模与约定

对于 $100\%$ 的数据，保证 $1\le x\le 100$，$1\le n\le 100$，$0\le p_i\le 10^4$。
