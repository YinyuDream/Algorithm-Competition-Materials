# T290861 死亡射线

## 题目背景

**机械化的心脏永不停搏，也不受制于情绪。那为什么人还要将性命托付于脆弱的血肉心肌？”—— 维克托**

## 题目描述

为了寻求更多的恕瑞玛水晶碎片用于光荣进化，**维克托**决定袭击**杰斯**位于皮尔特沃夫的三个实验室。这三个实验室分别是二维坐标平面上的三个点，而维克托可以用他的机械手臂发射一束死亡射线，摧毁一条折线段上的所有实验室——但是折线段的每一段都必须平行于坐标轴。额外地，这条折线段是一条若尔当弧，也就是说，这条折线段不能包含重合点或重合线段。又或者说，你可以从这条折线段的一端走到另一端，不经过重复的点也不遗漏任何一个部分。

为了节约能量，维克托希望寻找一条满足上述条件的折线段，使得三个实验室都位于这条折线段上（包括端点），并且折线段的总长度尽可能小。

## 输入格式

输入包含三行，每行包括两个整数 $x$ 和 $y$ ，描述了一个实验室的坐标 $(-10^9 \leq x, y \leq 10^9)$ 。保证三个点不重合。

## 输出格式

输出一行一个整数 $l$ ，代表你选择的满足题目条件的最短折线段的长度。

## 输入输出样例 #1

### 输入 #1

```
1 1
3 5
8 6

```

### 输出 #1

```
12

```
