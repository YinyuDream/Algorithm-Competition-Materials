# T290878 优美串

## 题目描述

我们认为一个长度为 $n$ 的 $\texttt{01}$ 字符串 $S$ 是**优美的**，当且仅当 $S$ 可以进行 $n - 1$ 次操作，使其变为含有单个 $\texttt{01}$ 字符的字符串 $\texttt{0}$ 或 $\texttt{1}$，每次从以下两种操作中**选择一种**。
+ 选择 $S$ 的任意一个子串 $\texttt{01}$，将其替换为 $\texttt{1}$
+ 选择 $S$ 的任意一个子串 $\texttt{10}$，将其替换为 $\texttt{0}$

输入 $\texttt{01}$ 字符串 $S$，询问 $S$ 有多少个**非空子串**是优美的。

字符串 $S$ 的 子串 ，$S[i..j]，i≤j$ ，表示 $S$ 串中从 $i$ 到 $j$ 这连续的一段，也就是顺次排列 $S[i],S[i+1],\ldots,S[j]$ 形成的字符串。

## 输入格式

第 $1$ 行一个正整数 $n$ 表示 $\texttt{01}$ 字符串的长度。

第 $2$ 行一个 $\texttt{01}$ 字符串。

## 输出格式

一个整数表示答案。

## 输入输出样例 #1

### 输入 #1

```
2
10
```

### 输出 #1

```
3
```

## 输入输出样例 #2

### 输入 #2

```
4
1001
```

### 输出 #2

```
8
```

## 输入输出样例 #3

### 输入 #3

```
5
00110
```

### 输出 #3

```
11
```

## 说明/提示

### 数据范围

$n \leq 2 \cdot 10^5$

### 样例解释

串 $\texttt{1001}$ 是优美的，因为可以进行 $3$ 次操作：

第 $1$ 次 $\texttt{\underline{10}01}$ $\rightarrow$ $\texttt{001}$

第 $2$ 次 $\texttt{0\underline{01}}$ $\rightarrow$ $\texttt{01}$

第 $3$ 次 $\texttt{\underline{01}}$ $\rightarrow$ $\texttt{1}$
