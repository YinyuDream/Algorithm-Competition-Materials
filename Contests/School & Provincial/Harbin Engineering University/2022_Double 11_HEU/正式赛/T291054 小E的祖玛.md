# T291054 小E的祖玛

## 题目描述

小E正在玩祖玛改。

祖玛改的规则如下：

游戏中一共有$m$种颜色的球，如果有$a_i$个第$i$种颜色的球连在一起，它们就会被消除。

游戏开始时会生成一条有$n$个球的链（保证不会出现大于等于$a_i$个第$i$种颜色的球相邻），游戏一共进行$k$轮，第$i$轮你会获得一个$c_i$颜色的球，然后你可以将这个球插到链的任意位置。但是，小E不想思考，因此**小E拿到球后只会将球插入到链的末尾**。如果任意时刻链上的球被全部消除，那么小E会取得胜利；如果第$k$轮结束后仍未胜利，则小E将会失败。

小E发现这样玩总是输多赢少，所以小E通过特殊方式获得了一个万能球，万能球可以被视为任意颜色的球。

在获得一个球后，小E可以选择将先万能球插入到末尾，再使用获得的球。由于小E是一个目光短浅的人，所以只有在当前回合能取得胜利时，小E才会使用万能球。

小E想要你告诉他，对于一局游戏，他是否能取得胜利，如果能，请告诉他最早能在哪一回合胜利，如果不能，请告诉他场上最后会剩下多少个球。

## 输入格式

第一行为三个整数，分别为$n,m,k$。

第二行为$m$个整数，第$i$个整数为$a_i$。

第三行为$n$个整数，表示初始链上的球的颜色$b_i$。

第三行为$k$个整数，为每轮获得的球的颜色$c_i$。

## 输出格式

第一行，如果小E能胜利，输出`Win`，否则输出`Lose`。

第二行，如果小E能胜利，输出最早能在哪一回合胜利，否则输出场上最后会剩下多少个球。

## 输入输出样例 #1

### 输入 #1

```
6 3 4
3 2 3
2 1 1 2 3 3
3 2 2 2
```

### 输出 #1

```
Win
3
```

## 输入输出样例 #2

### 输入 #2

```
1 1 1
3
1
1
```

### 输出 #2

```
Win
1
```

## 说明/提示

### 样例解释
#### 样例一

第一回合`2 1 1 2 3 3 3 -> 2 1 1 2`

第二回合`2 1 1 2 2 -> 2 1 1`

第三回合先使用万能球`2 1 1 ? -> 2`，再使用普通球`2 2 -> Win`

### 数据范围
$1\leq n,m,k\leq100000$

$2\leq a_i\leq n$

$1\leq b_i,c_i\leq m$
