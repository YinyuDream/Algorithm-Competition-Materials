# T290943 芳香串

## 题目描述

众所周知，小 $B$ 是一个芳香的人，他在今年的 $11$ 月 $4$ 日 $5$ 时 $14$ 分得到了一个只包含小写英文字母的字符串 $S$，不过他认为这个串不够符合他的品味。

一个字符串 $S$ 符合小 $B$ 的品味当且仅当其中有**一半以上**（**不包括一半**）的字符是 $\texttt{a}$。

小 $B$ 可以通过删除任意多个字符使 $S$ 符合他的品味，他还想让这个符合品味的字符串长度尽可能长。

可惜现在是 $5$ 时 $14$ 分，他太困了，于是把这个问题抛给了你。

你对小 $B$ 白嫖劳动力的行为非常不满，所以只打算告诉他最长的长度。

## 输入格式

第一行一个整数 $n$ 表示字符串长度。

第二行一个小写英文字母组成的字符串 $S$，含义与题目描述中相同。

## 输出格式

一个整数表示可以通过删除字符得到的最长的符合小 $B$ 品味的字符串的长度。

## 输入输出样例 #1

### 输入 #1

```
2
ab
```

### 输出 #1

```
1
```

## 输入输出样例 #2

### 输入 #2

```
13
henhenhenaaaa
```

### 输出 #2

```
7
```

## 输入输出样例 #3

### 输入 #3

```
8
awslawsl
```

### 输出 #3

```
3
```

## 说明/提示

### 数据范围

$n \leq 100$。

保证 $S$ 中至少存在一个 $\texttt{a}$ 且输入的 $S$ 不符合小 $B$ 的品味。
