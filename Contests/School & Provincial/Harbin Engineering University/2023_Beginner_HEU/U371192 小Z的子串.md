# U371192 小Z的子串

## 题目描述

小 Z 希望你构造一个长度为 $n$ 的、仅由 $\texttt{h}$、$\texttt{e}$、$\texttt{u}$ 三种字符组成的字符串，需要保证该字符串包含恰好 $k$ 个 $\texttt{heu}$ 子串。

字符串 $S$ 的 子串 ，$S[i..j]，i≤j$ ，表示 $S$ 串中从 $i$ 到 $j$ 这一段，也就是顺次排列 $S[i],S[i+1],\ldots,S[j]$ 形成的字符串。

例如： $\texttt{Har}$ 和 $\texttt{bin}$ 均是 $\texttt{Harbin}$ 的子串，而 $\texttt{zHa}$ 和 $\texttt{Hab}$ 均不是 $\texttt{Harbin}$ 的子串。

## 输入格式

输入一行，两个正整数 $n,k$，用空格隔开，如题意所示。

## 输出格式

输出一行，如果无法构造满足题意的字符串，输出 `-1` ；

否则输出一个长度为 $n$ 的合法字符串。

请注意，答案可能不唯一，输出任意一组满足题意的答案即可。

## 输入输出样例 #1

### 输入 #1

```
5 1
```

### 输出 #1

```
heueu
```

## 输入输出样例 #2

### 输入 #2

```
5 3
```

### 输出 #2

```
-1
```

## 说明/提示

$1 \leqslant n, k \leqslant 10^5$。
