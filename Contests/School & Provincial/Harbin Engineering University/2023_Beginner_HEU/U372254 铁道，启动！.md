# U372254 铁道，启动！

## 题目描述

$hkp$ 是一位忠实的星穹铁道玩家，抽卡之神降下神恩，赐予他$n$次抽卡次数，但是因为他曾经玩过 $Genshin$ $Impact$，抽卡之神惩罚他，单次抽卡的次数必须为 $n$ 的因数，即 $n$ 是 $x$ 的整数倍数.

$hkp$ 想知道，如果把自己所有可能的单次抽卡次数 $x$ 从小到大排成一个数列，这个数列中第 $k$ 小的数是多少？

但是他很笨，所以请你完成一个程序，帮他找到这个第 $k$ 小的数，如果不存在这个第 $k$ 小的数，则输出 $-1$ .

## 输入格式

输入一行，两个正整数 $n$ 和 $k$，用空格隔开，如题意所示.

## 输出格式

输出一个数，即为所求的第 $k$ 小的数，如果不存在，输出 $-1$.

## 输入输出样例 #1

### 输入 #1

```
12 3
```

### 输出 #1

```
3
```

## 输入输出样例 #2

### 输入 #2

```
4 4
```

### 输出 #2

```
-1
```

## 说明/提示

### 样例解释

在样例 $1$ 中，得到的数列为 $[1, 2, 3, 4, 6, 12]$ ，其中第 $3$ 小的数是 $3$.

在样例 $2$ 中，得到的数列为 $[1, 2, 4]$ ，总共只有 $3$ 个数，所以不存在第 $4$ 小的数.


### 数据范围

$1 \leqslant n, k \leqslant 10^5$
