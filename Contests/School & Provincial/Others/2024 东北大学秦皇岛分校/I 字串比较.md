# 字串比较

## 题目描述

你有两个由小写字母组成的字符串 $s_1$ 和 $s_2$，你要比较两个串的某一个子串的字典序大小。

## 输入描述

第一行输入三个整数 $n,m,q$ $(1 \leq n,m,q \leq 2 \cdot 10^5)$分别表示$s_1$的长度、$s_2$的长度和询问的个数

第二行第三行分别是由小写字母组成的字符串$s_1$ 和 $s_2$

之后 $q$ 行每行四个整数表示 $l_1,r_1,l_2,r_2$ $(1 \leq l_1 \leq r_1 \leq n, 1 \leq l_2 \leq r_2 \leq m)$ 表示 $s_1$ 的子串区间 $[l_1,r_1]$ 和 $s_2$ 的子串区间 $[l_2,r_2]$ 。

保证两个子串的**长度相同**。

## 输出描述

对于每个询问，输出一个比较结果 $ans \in \{<,=,>\}$，表示比较结果。

## 示例1

### 输入

```
3 3 3
abc
bca
1 1 3 3
1 2 2 3
1 1 1 1
```

### 输出

```
=
<
<
```
