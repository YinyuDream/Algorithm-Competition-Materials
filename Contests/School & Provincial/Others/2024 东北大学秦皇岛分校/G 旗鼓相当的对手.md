# 旗鼓相当的对手

## 题目描述

小A最近正沉迷于一款网络多人对战游戏，游戏怪诞的分队机制总是让小A的血压居高不下。

叫苦不迭的小A找到了你，请你帮游戏公司设计一个算法来平衡地将玩家分为两队，保护小A的游戏体验。

我们认为两队玩家实力之和的差越小，分组越平衡。

## 输入描述

第一行包含一个整数 $n$ $(1 \le n \le 300)$，表示玩家总数。

第二行包含 $n$ 个整数 $a_i$ $(1 \le a_i \le 200000)$，表示每个玩家的实力，保证 $\Sigma a_i \le 200000$。

## 输出描述

一个整数，表示两队玩家实力之和的差的最小值

## 示例1

输入

```
4
1 2 3 100
```

输出

```
94
```

## 示例2

输入

```
6
1 3 5 7 8 9
```

输出

```
1
```
