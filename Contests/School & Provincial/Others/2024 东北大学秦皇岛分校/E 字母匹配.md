# 字母匹配

## 题目描述

在东秦的字母王国，有两种字母，一种是小写字母，一种是大写字母，而每个小写字母都可以和一个大写字母配对，现在给定一个字符串，并可以执行至多不超过k次的操作，每次操作可以把一个小写字母变成大写字母，也可以把一个大写字母变成小写字母，小瑞想知道最多可以有多少对大小字母可以配对。

A可以和a配对，但不可以和b配对，每种大写字母或者小写字母只能配对其对应的小写字母或者大写字母。

## 输入描述:

第一行输入两个整数 $n, k$ $(1 \leq n, k \leq 2*10^5)$ 分别表示字符串长度和操作次数。
第二行输入字符串

## 输出描述:

输出答案

## 示例1

### 输入

```
11 2
aAaaBACacbE
```

### 输出

```
5
```
