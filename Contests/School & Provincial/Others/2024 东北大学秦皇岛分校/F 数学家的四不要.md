# 数学家的四不要

## 题目描述

相传有位数学家喜欢研究一个数字的性质，从小研究到大，但是有些数字他很讨厌，因此他不会去研究这些数字。

他曾说这数字他有四不要：偶数不要，质数不要，三角数不要，卡特兰数不要。

请问 $n$ 以内正整数他至多能研究多少个？

**名词解释：**

**质数**是只能被1和自身整除的正整数，如2、3、5、7等。

**三角数**是由连续自然数相加得到的数列，第n个三角数等于1到n的自然数之和，如1、3、6、10等。

**卡特兰数**是一种组合数学中的数列，描述了在不同问题中可能的排列或匹配方式的数量，如括号匹配、二叉树结构等。

**卡特兰数的计算方法如下**

$C_n = \sum_{i=0}^{n-1} (C_i \cdot C_{n-i-1})$

其中, $C_i$ 表示第 $i$ 个卡特兰数，特别地，前两个卡特兰数都是1。

## 输入描述

输入在一行中给出 $n$ $(1 \le n \le 10^5)$。

## 输出描述

在一行中输出他至多能研究多少个n以内的正整数。

## 示例1

输入

```
10
```

输出

```
1
```
