# 凸包

## 题目描述

在二维平面上给定 $n$ 个互不重合的整点 $P_i = (x_i, y_i)$。题目保证对于任意三个互不相同的点，它们均**不共线**。

你需要从这些点中选出两个**非空且不相交**的点集 $A$ 和 $B$，使得由点集 $A$ 构成的凸包$\dagger$与由点集 $B$ 构成的凸包**完全不相交**（即两个凸多边形的内部及边界均无公共点）。

注意：你不需要使用所有的点。只要满足 $A \cap B = \emptyset$ 且两个凸包在几何上完全分离即可。本题保证在给定条件下一定有解。如果存在多种方案，输出任意一种即可。

$\dagger$ 给定点集 $S$ 的凸包是指包含 $S$ 中所有点的**最小凸多边形**。直观地说，如果你在点集的所有点上钉上钉子，并用一根橡皮筋框住所有钉子，橡皮筋所围成的区域即为该点集的凸包。

**注意**：凸包至少要包含三条边，下图展示了一个点集对应的凸包：

![图片](https://uploadfiles.nowcoder.com/images/20260322/0_1774153523868/6E8095CE867C0F15DF6FFB5F4BAF54CB)

点集$\{A,B,C,D,E,F\}$对应的凸包为多边形$BCDE$

## 输入描述:

第一行一个整数 $n$ ($6 \le n \le 500$)。

接下来 $n$ 行，每行两个整数 $x_i,y_i$ ($|x_i|,|y_i| \le 10^9$)，表示编号为 $i$ 的点 $P_i$ 的坐标。

## 输出描述:

如果存在多种方案，输出任意一种：

第一行输出两个整数 $k,m$，表示集合 $A,B$ 的大小。

第二行输出 $k$ 个互不相同的整数，表示属于集合 $A$ 的点的编号。

第三行输出 $m$ 个互不相同的整数，表示属于集合 $B$ 的点的编号。

## 示例1

### 输入

```
6
0 0
1 0
0 1
2 2
1 2
2 1
```

### 输出

```
3 3
1 3 2
6 4 5
```
