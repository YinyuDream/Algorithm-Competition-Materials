# 微软大战代码

小 P 最近迷上了一款名为《微软大战代码》的游戏。这款游戏历史悠久，发展出了无数个版本，而每个版本又可能衍生出自己的后续版本。

为了理清这些版本的关系，小 P 将它们整理成了一棵版本树：

- 版本 $1$ 是根节点（原版），没有前作。
- 对于 $i \ge 2$，版本 $i$ 的直接前作为 $x_i$（$1 \le x_i < i$），且每条边 $(x_i, i)$ 上有一个评价字母 $ch_i$，为小写 `a` 到 `z`，字母越小表示改版越精良。

对于任意一个版本 $u$，其**评价串**定义为从根节点（版本 $1$）到版本 $u$ 的路径上所有边的字母按顺序拼接而成的字符串。根节点的评价串为空串。

小 P 决定根据以下规则对所有版本进行排序：

- 按评价串的**字典序升序**排序，也就是字典序越小的版本，排名越靠前。
- 若两个版本的评价串完全相同，则**版本序号较小**的排在前面。

**注**：字典序指通常的字符串比较方式：从左到右逐个字符比较，第一个不同字符的较小者字典序更小；若一个字符串是另一个的前缀，则较短的字符串字典序更小。

## 输入描述:

第一行包含一个整数 $T$（$1 \le T \le 10^4$），表示测试数据组数。

对于每组测试数据：

- 第一行包含一个整数 $n$（$1 \le n \le 10^5$），表示版本总数。
- 接下来 $n-1$ 行，每行描述一个版本 $i$（$i = 2, 3, \dots, n$），包含一个整数 $x_i$ 和一个小写字母 $ch_i$，表示版本 $i$ 的前作为 $x_i$，对应边的评价为 $ch_i$。

保证 $x_i < i$，因此输入顺序与版本编号一致，且形成一棵以 $1$ 为根的有根树。

所有测试数据的 $n$ 之和不超过 $10^5$。

## 输出描述:

对于每组数据，输出一行 $n$ 个整数，为按照上述规则排序后的版本序号，相邻序号间用一个空格隔开。

## 样例输入输出

**输入**

```
2
3
1 b
2 a
6
1 z
1 a
2 b
2 a
5 c
```

**输出**

```
1 2 3
1 3 2 5 6 4
```
