# fufu 购买计划

fufu 软乎乎地看着你，你的大脑已经停止思考，只剩下一个念头：买它！

![图片](https://uploadfiles.nowcoder.com/images/20260322/0_1774117436400/CC8DCFD00765CBBC0F5961D3996D3D06)

你有价值 $1,2,\cdots,n$ 的硬币各一枚，想要购买价值为 $m$ 的 `fufu`，你需要选出若干枚硬币，价值之和**恰好**为 $m$。

可恶的老板给出了额外的 $n$ 个要求，第 $i$ 个要求是：

- 价值小于等于 $i$ 的硬币至多使用 $a_{i}$ 枚。

请你判断老板的要求能否满足，以及如何支付硬币才能满足老板的要求。

## 输入描述:

第一行输入一个整数 $T$（$1 \le T \le 1000$），表示数据组数。

对于每组数据：

- 第一行输入一个整数 $n, m$（$1 \le n \le 10^6$, $1 \le m \le \frac{n(n+1)}{2}$）。
- 第二行包含 $n$ 个整数 $a_i$（$0 \le a_i \le i$）。

保证所有数据组中 $n$ 的总和不超过 $10^6$。

## 输出描述:

对于每组数据：

- 如果可以，先输出一行一个整数 $k$，然后升序输出一行 $k$ 个互不相同的硬币价值；
- 否则输出一行一个整数 $-1$。

## 示例1

输入

```
1
4 5
0 2 2 3
```

输出

```
2
2 3
```
