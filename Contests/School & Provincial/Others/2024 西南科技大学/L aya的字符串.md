# aya的字符串

$\text{aya}$ 来到妖怪之山游玩，想要到达山顶需要一个特殊的字符串 $S$。

$S$ 是由两个大小写字母 且 非空字符串 $A,B$ 组成，并且满足以下条件：

- $S = AB$，也就是说 $S$ 是按照 $AB$ 的顺序拼接而成。
- $A$ 和 $B$ 是由小写字母组成。
- $A$ 中每种字母只出现了一次。
- $B$ 是由两个相同的字符串 $b$ 拼接而成，也就是 $B=bb$。

例如ayaa 是符合条件的，因为 ayaa = ay + aa ，但 shameimaru 和 ayAA 不符合条件。

请你判断 $\text{aya}$ 的字符串能不能满足条件。

## 输入描述:

第一行一个整数 $T$ $(1 \le T\le10^{4})$，表示有t组测试数据。

接下来 $T$ 组：

每组数据第一行一个整数 $n$ $(1 \le n\le  2×10^{5})$，表示字符串长度。

第二行一个长度为 $n$ 的仅包含大小写字母 的字符串 $S$。

保证所有测试用例中 $n$ 的总和不超过 $2 \times 10^{5}$，即 $\sum n \le 2 \times 10^{5}$。

## 输出描述:

如果字符串满足条件，则输出 aya， 否则输出 shameimaru。

## 示例1

输入

```
4
4
ayaa
5
abcde
4
ayAA
8
abcdefef
```

输出

```
aya
shameimaru
shameimaru
aya
```
