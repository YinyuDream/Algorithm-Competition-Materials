# KAKAZL的时间魔咒

$\text{KAKAZL}$ 最喜欢在外面探索了，有一次他发现一个山洞，山洞里面有一个神奇的时钟。

当时钟显示的时间满足对称形式时，时钟会发出一道美丽的光芒。

- **对称：** 小时和分钟所显示的数字以冒号为轴对称图形，例如 $13:31$ 是一个对称形式，$00:00$ 和 $03:30$ 也是一个对称形式，但 $12:12$ 不是一个对称形式。

给出你当前的时间，判断距离下一次发光需要等待多少分钟，输出下一次发光时间和等待的分钟数。

## 输入描述:

第一行输入一个整数 $t$ $(1 \leq t \leq 2×10^5)$，表示测试组数。

接下来 $t$ 行，每行输入一个由小时 $h$，冒号 "$:$"  和分钟 $m$ 组成的时间 $(0 \leq h \lt 24,0 \leq m \lt 60)$

保证输入的时间 **符合现实情况**，当$(0 \leq h,m \lt 10)$的时候。$h$ 与 $m$ 存在前导 $0$，且 $24:00$ 不存在，应该为 $00:00$。

## 输出描述:

一共 $t$ 组输出，每组输出两行。

第一行输出一个时间，表示下一次发光时间。

第二行输出到达下次发光所需要等待的分钟数。

## 示例1

输入

```
6
23:50
11:11
13:31
20:03
17:20
07:04
```

输出

```
00:00
10
11:11
0
13:31
0
21:12
69
20:02
162
10:01
177
```
