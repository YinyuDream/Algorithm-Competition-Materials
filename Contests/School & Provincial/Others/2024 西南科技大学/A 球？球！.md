# 球？球！

## 题目描述

众所周知，$\text{zy}$ 和 $\text{sdy}$ 喜欢打排球。

两人相互扣球，每一次扣球使用的力量是不同的，如果扣球的 **力量值** 超过了对方场地的 **出界值**，就代表本次扣球出界。

由于场地原因，双方的场地并不相同，所以双方场地的 **出界值** 也有可能不同，

如果扣球出界，则自己 **减少** $2$ 分，如果扣球成功，则自己 **增加** $1$ 分。

**需要注意的是，分数最低是** $0$ **分，不会出现负数**。

已知 $\text{zy}$ **先扣球**，接下来两人 **轮流扣球**，请你计算一下他们谁得分更多。

## 输入描述

第一行一个正整数 $T(1\le T\le 10^4)$ 表示测试组数。

接下来 $T$ 组：

每组第一行三个正整数 $n,z,s(1\le n\le 10^5,0\le z,s\le 10^9)$ 分别表示每人的扣球次数、$zy$ 场地的出界值、 $sdy$ 场地的出界值。

接下来一行 $n$ 个正整数 $a_i(0\le a_i\le 10^9)$ 表示 $zy$ 第 $i$ 次扣球的力量值。

接下来一行 $n$ 个正整数 $b_i(0\le b_i\le 10^9)$ 表示 $sdy$ 第 $i$ 次扣球的力量值。

**保证所有测试用例中** $n$ **的总和不超过** $10^{5}$，**即** $\sum n \le 10^5$。

## 输出描述

输出 $T$ 行，对于每组测试数据如果 $\text{sdy}$ 得分多则输出 sdy，如果 $\text{zy}$ 得分多则输出 zy，如果二人分数相同输出 none。

## 示例1

输入

```
1
2 3 5
2 3
3 5
```

输出

```
zy
```
