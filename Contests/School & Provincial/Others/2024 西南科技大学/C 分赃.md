# 分赃

## 题目描述

$\text{ChuTian}$ 新买了 $n$ 颗糖果，但不幸的是在回家的路上遇到了两个劫匪 —— $\text{clx}$ 和 $\text{yxy}$。

现在， $\text{clx}$ 和 $\text{yxy}$ 准备分赃， 其中有一颗独一无二的典藏糖果。 

两人决定轮流拿糖果，每次可以拿 $1$ 颗或者 $3$ 颗， 典藏糖果必须 **最后一个** 被拿走。

$\text{clx}$ 先手，并且两人都以最优策略进行拿取。

$\text{ChuTian}$ 十分珍视那颗典藏糖果，所以他需要提前计算出谁能拿走典藏糖果，这样才能在劫匪落单的时候把典藏糖果劫回来。

请你告诉他，最后是谁拿到了典藏糖果。

## 输入描述

输入一个整数 $n$ $( 1 \le n \leq 10^{100} )$， 表示 $\text{ChuTian}$ 买了 $n$ 颗糖果。

## 输出描述

输出一行，如果典藏糖果是 $\text{clx}$ 拿走的输出 clx，如果典藏糖果是 $\text{yxy}$ 拿走的请输出 yxy。

## 样例输入输出

**示例1**

输入：
```
5
```

输出：
```
clx
```

## 备注

注意 ： $\text{ChuTian}$ 财力雄厚，买的糖果数量有可能很大噢！
