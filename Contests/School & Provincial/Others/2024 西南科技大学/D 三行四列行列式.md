# 三行四列行列式

> 前情提要：没有三行四列行列式，题目名是在玩梗。行列式必须是方阵，即行数和列数相等，才能进行计算。

你现在有一个方阵（可以视为 $n\times n$ 的矩形），初始方阵中第 $i$ 行第 $j$ 列的元素用 $a_{(i,j)}$ 表示。

现在你需要 **按顺序** 做如下操作，并请你输出操作结束之后的方阵。

1. 记录第 $x$ 行的元素 $a_{(x,1)},a_{(x,2)},...a_{(x,n)}$ 分别为序列 $R$ 中的 $R_{1},R_2,...R_n$;
2. 记录第 $y$ 列的元素 $a_{(1,y)},a_{(2,y)},...a_{(n,y)}$ 分别为序列 $C$ 中的 $C_{1},C_2,...C_n$;
3. 使用序列 $R$ 覆盖原方阵的第 $y$ 列，即 $a_{(1,y)}=R_1,a_{(2,y)}=R_2,...a_{(n,y)}=R_n$ ;
4.  使用序列 $C$ 覆盖原方阵的第 $x$ 行，即 $a_{(x,1)}=C_1,a_{(x,2)}=C_2,...a_{(x,n)}=C_n$ ;
5. 第 $x$ 行与第 $y$ 列的交点 $a_{(x,y)}$ ，令其重新赋值为 $\lceil \frac{R_x+C_y}{2} \rceil$ 。

**注**：$\lceil \rceil$ **表示向上取整符号，如** $\lceil 2.5 \rceil=3$ ,$\lceil 5.0 \rceil=5$

给出的示例交换如样例与提示区所示。

## 输入描述:

第一行输入一个正整数 $n$ $(1\le n\le 10^3)$ ，表示给出的初始方阵是 $n$ 行 $n$ 列的矩阵。

接下来输入一个 $n\times n$ 的矩阵 $a$ ，$a_{(i,j)}$ $(1\le a_{(i,j)}\le 4\times 10^6)$ 表示矩阵第 $i$ 行第 $j$ 列的初始元素值。

最后输入一行两个正整数 $x,y$ $(1\le x,y\le n)$ 。表示操作的参数，含义见题目描述。

## 输出描述:

输出按顺序操作后的矩阵。

## 示例1

输入

```
3
1 2 3
4 5 6
7 8 9
3 1
```

输出

```
7 2 3
8 5 6
5 4 7
```

## 备注:

对于样例 $1$ ：
- $x=3,y=1$ ，所以 $R=\{7,8,9\} ,C=\{1,4,7\}$ 。
- 将 $R$ 覆盖到第 $y=1$ **列**，所以矩阵变为如下形态：
&nbsp; &nbsp; &nbsp; &nbsp;$7$ $2$ $3$
&nbsp; &nbsp; &nbsp; &nbsp;$8$ $5$ $6$
&nbsp; &nbsp; &nbsp; &nbsp;$9$ $8$ $9$
- 将 $C$ 覆盖到第 $x=3$ **行**，所以矩阵变为如下形态：
&nbsp; &nbsp; &nbsp; &nbsp;$7$ $2$ $3$
&nbsp; &nbsp; &nbsp; &nbsp;$8$ $5$ $6$
&nbsp; &nbsp; &nbsp; &nbsp;$1$ $4$ $7$
- 最后更新第 $3$ 行与第 $1$ 列的交点 $a_{(3,1)}$ 为 $\lceil \frac{R_x+C_y}{2} \rceil=\lceil \frac{9+1}{2} \rceil=5$ ，所以矩阵最后变为如下形态：
&nbsp; &nbsp; &nbsp; &nbsp;$7$ $2$ $3$
&nbsp; &nbsp; &nbsp; &nbsp;$8$ $5$ $6$
&nbsp; &nbsp; &nbsp; &nbsp;$5$ $4$ $7$
