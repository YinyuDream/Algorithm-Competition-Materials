# 加训

Charan 因为最近经常加训，导致得了老花眼。

现在面前有一个字符串 $S$，$S$ 是一个 **没有相邻的重复字母** 的字符串。

由于老花眼的问题，他看到的字符串 $S'$ 是 $S$ 中一些字符发生了 **重影** 后的字符串。

**重影**： 即一些字符连续出现多次，例如看到字符串 abcde，由于 a,d字符重影，而得到 aabcddde，或者看到字符串 a 由于 a 字符重影，而得到 aaaaaa。

Charan 想知道，将他看到的字符串 $S'$ 恢复出的原字符串 $S$ 后是否为 $T$ $(T$ 可能有相邻的重复字母$)$。

## 输入描述:

第一行输入一个正整数 $t$ $(1\le t\le 10^4)$ ，表示测试数据组数。

对于每组测试数据：

第一行输入两个正整数 $n,m$ $(1\le n\le 10^5,1\le m \le n)$ ，分别字符串 $S'$ 的长度和 $T$ 的长度。

第二行输入一串长度为 $n$ 的字符串 $S'$ (仅含小写字母)。

第二行输入一串长度为 $m$ 的字符串 $T$ (仅含小写字母)。

保证所有测试用例中 $n$ 的总和不超过 $10^{6}$，即 $\sum n \le 10^6$。

## 输出描述:

每组测试数据输出一行, 如果 $S$ 与 $T$ 相同输出 YES , 否则输出 NO。

可以用任意大小写输出答案。例如，字符串 yEs、yes、Yes 和 YES 都将被视为肯定回答，否定回答同理。

## 示例1

输入

```
3
9 5
aabccddde
abcde
5 1
aaaaa
a
7 5
aaabccc
aabcc
```

输出

```
YES
YES
NO
```

## 备注:

对于第一个样例：$aabccddde → abcde$，原串与 $T$ 相同，输出 YES。

对于第二个样例：$aaaaa → a$，原串与 $T$ 相同,输出 YES。

对于第三个样例：$aaabccc → abc$，原串与 $T$ 不同 ，输出 NO。
