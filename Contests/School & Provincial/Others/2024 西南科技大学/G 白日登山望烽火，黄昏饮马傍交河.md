# 白日登山望烽火，黄昏饮马傍交河

## 题目描述

将军想要从 $A$ 地到达 $B$ 地，但此时将军的宝马已经很渴了，所以必须先前往河边饮水。

地图被抽象成一个直角坐标系，$x$ 轴和 $y$ 轴是两条河。

将军想要知道，前往哪条河饮水可以使 **总路线最短** （保证不存在经过两条河的路线都为最短的情况）。

## 输入描述

第一行一个正整数 $T(1\leq T \leq 10^{4})$，代表测试组数。

对于每组测试：

仅包含一行四个整数 $x_1,y_1,x_2,y_2( -10^{4}\leq x_1,y_1,x_2,y_2 \leq 10^{4} )$，$(x_1,y_1)$ 表示 $A$ 地坐标，$(x_2,y_2)$ 表示 $B$ 地坐标。

## 输出描述

输出 $T$ 行，如果先去以 $x$ 轴为河的河边饮水，输出 x，如果先去以 $y$ 轴为河的河边饮水，输出 y。

（**保证不存在经过两条河的路线都为最短的情况**）。

## 示例1

输入

```
2
1 2 3 4
8 7 6 5
```

输出

```
y
x
```

## 示例2

输入

```
2
1 0 1 1
1 1 0 1
```

输出

```
x
y
```

## 备注

样例一解释：
可以证明，沿着 $A-C-B$ 前往 $y$ 轴饮水所走的距离小于沿着 $A-D-B$ 前往 $x$ 轴饮水所走的距离短，所以输出 y。![图片引用](https://uploadfiles.nowcoder.com/images/20240924/0_1727108184830/384707D046E3BCF4EC1FB23BFB6106C5)
