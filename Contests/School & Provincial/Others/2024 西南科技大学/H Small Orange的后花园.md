# Small Orange的后花园

> 你历经千难万险终于来到了 Small Orange 的后花园，恭喜也欢迎你！ Small Orange 的后花园里有一个宝藏，解开下述问题以后你将获得这个宝藏，而这个宝藏将在赛后揭晓！

已知斐波那契数列 $\{fib\}$ 的首项 $fib_1=1$ ，第二项 $fib_2=1$ ，第 $n$ $(n\ge 3)$ 项 $fib_n=fib_{n-1}+fib_{n-2}$ 。

计算： $\sum\limits_{i=1}^{n} \sum\limits_{j=i}^{n} (fib_i-fib_j)^2$

结果可能很大，请对结果求余 998244353 后输出。

## 输入描述:

第一行输入一个正整数 $t$ $(1\le t\le 10^4)$ ，表示测试数据的组数。

对于每组测试数据：一行输入一个正整数 $n$ $(1\le n\le 10^5)$ ，表示参数 $n$。

**保证所有测试用例中** $n$ **的总和不超过** $10^{6}$，**即** $\sum n \le 10^6$。

## 输出描述:

每组测试数据输出一行一个整数表示 $\sum\limits_{i=1}^{n} \sum\limits_{j=i}^{n} (fib_i-fib_j)^2$ 的结果。

结果可能很大，请对结果求余 998244353 后输出。

## 示例1

输入

```
2
1
3
```

输出

```
0
2
```

## 备注:

$\sum$ 符号表示求和符号，例如：$\sum\limits _{i=1}^{n} i=1+2+3+...+n$ 。

* 对于样例 $1$ 的第一组测试数据：

$\sum\limits_{i=1}^{n} \sum\limits_{j=i}^{n} (fib_i-fib_j)^2=(1-1)^2=0$ 。

* 对于样例 $1$ 的第二组测试数据：

$fib_1=1$ ， $fib_2=1$ ，$fib_3=fib_{2}+fib_{1}=2$ 。

$\sum\limits_{i=1}^{n} \sum\limits_{j=i}^{n} (fib_i-fib_j)^2$

$=(fib_1-fib_1)^2+(fib_1-fib_2)^2$ $+(fib_1-fib_3)^2+(fib_2-fib_2)^2+(fib_2-fib_3)^2+(fib_3-fib_3)^2$ 

$=0+0+1+0+1+0$ 

$=2$
