# 奇妙的购物体验

这一天莎布工作完，突然想起自己，已经好久好久没有出门去采购东西了。

她提前收集了，她想去的 $N-1$ 家商场以及莎布家之间存在的路线的信息。

莎布对家和商场进行了一下编号。

莎布的家编号为 $1$ ，商场的编号为 $2-N$。

莎布通过提前收集信息，得到了 $M$ 条路径，每条路径由三个整数组成，$X,Y,Z$ ，代表 $X$ 地点与 $Y$ 地点可以互相到达，路费需要 $Z$ 元。（ $X$ 和 $Y$ ，只可能是商场或者莎布家）

莎布她想从家出发，把所有商场都走一遍，然后在这些商场卖的东西里面，进行采购，然后在回到家。（就是说即便没有在某个商场采购，她也想逛一逛）。

（**保证所有点是连通的**）

然而众所周知长时间不出门的人，会产生一种惯性，让自己想出门，但是懒得动。同时还有一种动力让自己想出门做某些事情。

莎布管这种不想出门的惯性叫做懒惰值（ $ldz$ ）。

莎布管让自己想出门做某些事情的动力叫做快乐值。

莎布想说服自己出门逛街，所以需要，快乐值**大于**懒惰值。

商场购物，买的东西可以让莎布产生快乐值。

现在莎布在网上查到了，这些商场卖的东西的所有信息，并且给这些商场卖的商品，标记了会让自己产生的快乐值。

莎布整理了这些商场内售卖的物品，整理出了 $K$ 条商品信息。

每条信息包含三个整数$S_{i},BW_{i},BQ_{i}$ 。代表第 $i$ 种商品，库存$S_{i}$件，第 $i$ 种商品的价格为$BW_{i}$，第 $i$ 种商品能给莎布带来的快乐值为$BQ_{i}$。

然后莎布翻箱倒柜，凑了几十张储蓄卡，和各种支付软件，凑出了$SHABU$元钱。

（不努力工作，不加班的莎布，很穷的，出去购物一次要凑全部现金。）

她想知道，这些钱除去路费之后。剩下的钱用来购物，最多可以产生多少快乐值，够不够让自己克服懒惰值出门购物。

（莎布表示，她必须要把每个商场最少走一次。如果不能把所有商场全走一次她宁愿不出门！）

但是众所周知莎布的数学一言难尽，甚至可以说出 $1$ 等于 $2$ 。

所以莎布想拜托你，帮她算出三个数据。

每个商场最少逛一次然后回到家需要的路费。

除去路费之后剩下的钱，去购物最多可以产生多少快乐值。

产生的快乐值够不够莎布说服自己出门逛街。如果够输出 $YES$ ，如果不够输出 $NO$ 。

如果钱甚至不够路费，后两种数据不用输出，更换为输出 Shub, go work overtime! 

## 输入描述:

第一行 $N,M,K,SHABU,ldz$。

$1\leq N \leq20$ 

$1\leq M \leq 2000$ 

$1\leq K \leq 2000$ 

$0\leq SHABU \leq 2000$

$0\leq ldz \leq 10000$

以下M行每行 三个整数 $X,Y,Z$。

$1\leq X,Y \leq 20$ 

$X \ne Y$

$0\leq Z\leq 2000$

以下K行每行 三个整数 $S_{i},BW_{i},BQ_{i}$。

$0< S_{i},BW_{i},BQ_{i}\leq 2000$

## 输出描述:

第一行一个整数
每个商场最少逛一次然后回到家需要的路费。
如果钱够路费 输出两行
除去路费之后剩下的钱，去购物最多可以产生多少快乐值。
产生的快乐值够不够莎布说服自己出门逛街。如果够输出 $YES$ ，如果不够输出 $NO$ 。
如果钱不够路费输出一行
Shub, go work overtime!
