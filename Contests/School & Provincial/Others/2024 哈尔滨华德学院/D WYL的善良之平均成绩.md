# WYL的善良之平均成绩

## 题目描述

$wyl$ 刚刚完成了自己的期末测试。

他一共考了 $n$ 个科目，每个科目都将获得一个 $1 \sim 5$ 之间的整数分数。

$wyl$ 是一个严于律己的学生，他希望自己的各科平均分（总分数除以 $n$）在四舍五入到最接近的整数后，能恰好达到 $5$。

为了达成这一目的，他可以侵入学校的成绩系统，修改掉若干个科目（也可以完全不修改）的成绩，凡是被修改的科目，都会被它直接改成 $5$ 分。

$wyl$ 是一名谨慎的学生，他希望在平均成绩达到期望的前提下，修改成绩的科目尽可能少，从而减少被其他学生发现的可能。

请你计算，他至少需要修改多少个科目的成绩，才能使得平均成绩达到期望。

## 输入描述

第一行包含一个整数 $n$。

$1 \le n \le 100$。

第二行包含 $n$ 个 $[1,5]$ 范围内的整数，表示小兰的各科成绩。

## 输出描述

一个整数，表示最少所需的修改成绩的科目数量。

## 示例1

**输入**

```
3
4 4 4
```

**输出**

```
2
```

## 示例2

**输入**

```
4
5 4 5 5
```

**输出**

```
0
```

## 示例3

**输入**

```
4
5 3 3 5
```

**输出**

```
1
```
