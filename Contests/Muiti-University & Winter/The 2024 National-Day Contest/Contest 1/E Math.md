# Math

## 题目描述

Given n, count the number of pairs of positive integers (x, y), such that $xy+1|x^2+y^2, 1\le x\le y \le n$.

There're t test cases in total.

## 输入描述:

First line contains an integer $t (1\le t\le 10^5)$. Next t lines each contains one integer n $(1\le n \le 10^{18})$.

## 输出描述:

Output t lines, denoting the answer of each testcase.

## 示例1

### 输入

```
10

10

100

1000

10000

100000

114514

1919810

20190104

123123123123

10000001000000
```

### 输出

```
2
5
14
31
65
67
158
326
5226
22091
```
