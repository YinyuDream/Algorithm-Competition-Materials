# 心绪的解剖

## 题目描述

小红拿到了一个正整数 $n$，她希望你将 $n$ 分解为三个斐波那契数之和。你能帮帮她吗？  
共有 $q$ 次询问。

所谓斐波那契数，即斐波那契数列中的某一项：\[0,1,1,2,3,5,8,13……\]（第三项起，每一项是前两项之和）。

## 输入描述

第一行输入一个正整数 $q$，代表询问次数。  
接下来的 $q$ 行，每行输入一个正整数 $n$，代表询问的正整数。

$$1\leq q \leq 10^5$$
$$1\leq n \leq 10^9$$

## 输出描述

输出 $q$ 行，每行输出一行答案。  
如果可以分解为三个斐波那契数之和，请输出三个非负整数。有多解时输出任意即可。  
如果无解，请直接输出 -1。

## 示例

### 示例输入

```
5
5
10
15
20
25
```

### 示例输出

```
0 0 5
2 0 8
5 5 5
2 5 13
21 1 3
```
