# 宇宙的终结

## 题目描述

众所周知，宇宙的终极答案是42。

但小红认为，宇宙有多个终极答案。如果一个数满足：该数等于恰好三个不同素数的乘积，那么它就是宇宙的终极答案之一。

小红希望你找到 $[l,r]$ 区间内的一个终极答案，你能帮帮她吗？

## 输入描述

两个正整数 $l,r$，用空格隔开。

$1\leq l \leq r \leq 100$

## 输出描述

如果该区间内不存在宇宙的终极答案，则输出 -1。

否则输出任意一个合法的答案。

## 示例

### 示例1

**输入**
```
40 50
```

**输出**
```
42
```

### 示例2

**输入**
```
45 55
```

**输出**
```
-1
```
