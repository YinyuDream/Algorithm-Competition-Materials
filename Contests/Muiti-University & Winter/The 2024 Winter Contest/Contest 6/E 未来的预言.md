# 未来的预言

## 题目描述

在淘汰制游戏中，有一个比较常用的机制：BO 机制。一般 BO 后面接一个奇数 $x$，代表比赛的总局数，两个队伍谁的胜局先超过 $x$ 的一半，谁就获胜了。例如，"BO3"代表三局两胜，"BO5"代表五局三胜，以此类推。  
现在给定游戏规则为 BOx，以及红队和紫队两个队伍接下来若干局的胜负情况（不一定比完，因为有可能没比完就结束了）。现在请你判断比赛得出胜负的时候，一共进行了多少局。

## 输入描述

第一行输入一个字符串，代表比赛机制。字符串保证是"BO"开头，然后和一个奇数正整数 $x$ 连接。  
第二行输入一个字符串，仅由'R'和'P'组成。'R'代表红队获胜，'P'代表紫队获胜。  
$1 \le x \le 10^5$  
字符串长度不超过 $10^5$。

## 输出描述

第一行输出一个字符串，代表获胜方。若红队获胜则输出"kou!"，若紫队获胜则输出"yukari!"，若还未分出胜负则输出"to be continued."  
第二行输出一个正整数，代表当前已经进行的局数。

## 示例

### 示例1

**输入**
```
BO5
RRPRPPPRP
```

**输出**
```
kou!
4
```

**说明**
五局三胜，进行完第 4 局时，红队已经赢了 3 场，因此红队获胜。后面的比赛将不会再进行。

### 示例2

**输入**
```
BO7
RRPPRP
```

**输出**
```
to be continued.
6
```
