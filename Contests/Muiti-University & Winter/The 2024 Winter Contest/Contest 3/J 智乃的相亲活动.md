# 智乃的相亲活动

## 题目描述

智乃举办了一个相亲活动，她邀请了 $N$ 位男嘉宾和 $M$ 位女嘉宾，现在男女嘉宾之间存在 $K$ 对双向的好感关系。

活动的第一步是选出若干位心动男/女嘉宾，按照如下的方式进行。

每个人都首先自己各自独立的从自己有好感的异性中选出一个人，若某个人至少被一位异性选中，则ta成为心动男/女嘉宾。

现在已知这 $K$ 对双向的好感关系，若每个人选择异性的方式都为从自己有好感的异性中等概率随机选择，则心动男/女嘉宾数目的期望分别是多少？

## 输入描述

第一行输入三个正整数 $N,M,K(1 \leq N,M,K \leq 10^{5})$ 表示男女嘉宾的数目，以及双向好感关系的数目。

接下来 $K$ 行，每行输入两个正整数 $u,v(1\leq u \leq N,1 \leq v \leq M)$ 表示第 $u$ 位男嘉宾和第 $v$ 位女嘉宾之间存在双向好感关系。

输入保证，不会出现重复的双向好感关系，且每个人至少存在一个好感关系。

## 输出描述

你可以从以下两种方式中任选一种自己喜欢的方式给出心动男/女嘉宾数目的期望。

1、输出两个实数作为答案，首先在第一行输出一个字符串"float"，接下来另起一行，输出两个实数表示心动男/女嘉宾的数目。若此这样做，当且仅当绝对误差或相对误差小于 $10^{-6}$ 时答案正确，即假设您提供的答案为 $a$，该问题的标准答案为 $b$ 时，您的答案正确，当且仅当 $\frac{|a-b|}{\max(1, |b|)}< 1 \times 10^{-6}$。

2、输出两个模 $10^{9}+7$ 下的模系实数作为答案，首先在第一行输出一个字符串"modint"，接下来另起一行，输出两个模实数 $P\cdot Q^{-1}(\mod 10^{9}+7)$ 表示心动男/女嘉宾的数目。

## 示例1

### 输入
```
2 3 4
1 1
2 1
2 2
2 3
```

### 输出
```
float
1.50000000 1.66666667
```

### 说明
对于男嘉宾：
有2位男嘉宾和3位女嘉宾，由于2号女嘉宾只对2号男嘉宾有好感。所以2号男嘉宾一定是心动男嘉宾。
而1号女嘉宾有0.5的概率选择1号男嘉宾，剩下0.5的概率重复选择了2号男嘉宾，所以总的期望为0.5*1+0.5*0+1=1.5。
对于女嘉宾：
与男嘉宾情况类似，1号男嘉宾只对1号女嘉宾有好感，所以1号女嘉宾必选，接下来还有1/3的概率重复，2/3的概率产生新的心动女嘉宾。
