## 题目描述

anon经常在一些地方夹带私货，比如在题目里夹。

anon可以在一个全是正数的数组中夹带一些 0，只要数组的除全 0 连续子数组外的每个连续子数组的平均数都大于等于 1，anon就不会被骂。

anon想知道在她不会被骂的情况下，她最多可以夹带多少个 0。

## 输入描述

第一行输入一个整数 $n$（$1 \leq n \leq 10^5$）表示数组长度。  
第二行输入 $n$ 个整数表示数组 $a$（$1 \leq a_i \leq 10^9$）。

## 输出描述

输出一个整数表示答案。

## 示例

### 示例 1

**输入**
```
6
1 1 4 5 1 4
```

**输出**
```
6
```

**说明**
```
anon可以把数组变成这样：
1 1 4 0 0 0 5 1 4 0 0 0
最多可以夹带6个0，可以证明，无法夹带更多的0。
```
