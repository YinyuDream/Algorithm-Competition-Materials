# anon的星星

## 题目描述

anon在玩一个游戏，她胜利一局会获得一颗星星，失败一局会失去一颗星星，没有平局。

anon忘记了自己胜利和失败的局数，只记得自己玩了 $n$ 局游戏，共获得了 $x$ 颗星星。

anon想知道她胜利了几局，失败了几局？

## 输入描述

第一行输入两个整数 $n(1 \leq n \leq 1000), x(-n \leq x \leq n)$。

## 输出描述

输出两个正整数表示胜利的局数和失败的局数。

若无法知道胜利的局数和失败的局数，则输出 -1。

## 示例

### 示例1

**输入**
```
3 1
```

**输出**
```
2 1
```

**说明**
胜利2局，失败1局，共获得1颗星星。

### 示例2

**输入**
```
3 0
```

**输出**
```
-1
```
