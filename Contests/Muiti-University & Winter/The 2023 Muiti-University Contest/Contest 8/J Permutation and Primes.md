# Permutation and Primes

## 题目描述

给定 $n$，你需要构造 $\{1, 2, \ldots, n\}$ 的一个排列 $P$，满足对于所有 $1 \le i < n$，要么 $P_i + P_{i+1}$ 是奇素数，要么 $|P_i - P_{i+1}|$ 是奇素数。

如果有多个解，输出任意一个。如果无解，输出 -1。

## 输入描述

第一行包含一个整数 $T$（$1 \le T \le 10^5$），表示测试用例数。

对于每个测试用例，输入仅一行包含一个整数 $n$（$2 \le n \le 10^5$）。

保证所有测试用例的 $n$ 之和不超过 $10^6$。

## 输出描述

对于每个测试用例：

如果存在解，输出一行包含 $n$ 个整数 $P_1, P_2, \ldots, P_n$（$1 \le P_i \le n$，$\forall \, 1 \le i < j \le n, P_i \neq P_j$），表示你构造的排列。

如果无解，输出一行 -1。

## 示例

### 示例输入

```
2
3
5
```

### 示例输出

```
1 2 3
5 2 1 4 3
```

### 说明

在第一个测试用例中，$1 + 2 = 3, 2 + 3 = 5$ 都是奇素数。

在第二个测试用例中，$|5 - 2| = 3, 2 + 1 = 3, |1 - 4| = 3, 4 + 3 = 7$ 都是奇素数。
