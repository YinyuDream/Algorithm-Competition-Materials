# 1061: ***斐波拉契数列

## 题目描述

菲波那契数列: 数列的第一个和第二个数都为1，接下来每个数都等于前面2个数之和。给出一个正整数k，要求菲波那契数列中第k个数是多少。

## 输入

一行，表示求第k个数的值,k为正整数

## 输出

一行，表示第k个数是多少

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1061)

```
5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1061)

```
5
```

## 提示

k<=60
