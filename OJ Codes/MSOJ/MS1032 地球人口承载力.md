# 1032: **地球人口承载力

## 题目描述

假设地球上的新生资源按恒定速度增长，照此推算，地球上现有资源加上新生资源可以供x亿人生活a年，活供y亿人生活b年。为了能够实现可持续发展，避免资源枯竭，地球最多能够养活多少亿人。四舍五入到小数点后两位。

## 输入

一行，包括四个正整数.x，a，y，b。每个数均不大于10000.

## 输出

一个实数，表示地球最多养活多少亿人，精确到小数点后两位

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1032)

```
110 90 90 210
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1032)

```
75.00
```

这是一道纯数学题！
