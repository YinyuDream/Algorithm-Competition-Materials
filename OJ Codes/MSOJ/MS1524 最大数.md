# 1524: 最大数

## 题目描述

现在请求你维护一个数列，要求提供以下两种操作：  
1. 查询操作 Q  L：查询当前数列中末尾L个数中的最大的数，并输出这个数的值。保证0<L<=len  
2. 插入操作 A  X：将X对一个固定的常数D取模，将所得答案插入到数列的末尾。X<=int，D<=int.  
初始时数列为空。

## 输入

第一行有两个数M和D，其中M表示操作数，D表示被取模的数。  
后面M行，每行一个操作，具体输入格式见【问题描述】

## 输出

对于每一个查询操作，输出对应的结果，每个结果占一行。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1524)

```
5 100
A 96
Q 1
A 97
Q 1
Q 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1524)

```
96
97
97
```

## 提示

对于20%的数据，M<=1000;  
对于60%的数据，M<=200000;  
对于100%的数据，M<=2000000;  

实际上可以在线
