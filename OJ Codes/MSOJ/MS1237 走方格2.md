# 1237: ***走方格2

## 题目描述

已知一个n\*m的方格，小明在方格的左上角（1,1）,要走到方格的右下角（n,n），请问有多少种走法，已知小明只可以向右和向下移动,并且中间有些方格是塌陷的(1表示不可以走，0表示可以走)，结果对123456取余。

## 输入

第一行n和m，后面一个n\*m的矩阵

## 输出

方案数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1237)

```
2 3
0 1 0
0 0 0
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1237)

```
1
```
