# 1526: 广场种树

## 题目描述

A城市有一个巨大的圆形广场，为了绿化环境和净化空气，市政府决定沿圆形广场外圈种一圈树。

园林部分得到指令后，初步规划处n个种树的位置，顺时针编号1到n，并且每个位置都有一个美观度Ai，如果在这里种树就可以得到Ai的美观度。但是由于A城市土壤费力欠佳，两棵树绝不能种在相邻的位置。现市政府给园林部分提供了m棵树苗并要求全部种上，请你帮忙设计种树方案使得美观度综合最大，如果无法将m棵树苗全部种上，输出“impossible”.

## 输入

第一行两个数n,m,分别表示位置数和树苗数；

第二行n个数Ai表示每个位置的美观度，0<=Ai<=int

## 输出

种上m棵树的最大美观度，如果不可以完全种上，输出“impossible”

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1526)

```
4 2
8 3 4 6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1526)

```
12
```

## 提示

对于20%的数据，n,m<=20;

对于40%的数据，n,m<=1000;

对于额外20%的数据，n,m<=200000,保证有一个位置的美观度为0；

对于100%的数据，n,m<=200000,Ai为非负整数;
