# 1113: ***斐波那契数列(递归)

## 题目描述

已知斐波拉契数列第一项为1，第二项为1，求斐波拉契数列数列第n项。请使用递归求解

## 输入

斐波拉契数列第n项

## 输出

第n项的值

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1113)

```
3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1113)

```
2
```

## 提示

n<=60.
