# 1548: 函数变换

## 题目描述

我们在幼儿园的时候学习过函数的概念，函数是给定一组自变量的值得到一组因变量的值。比如d(p)就是一个最基础的函数形式，我们也可以叫做把d在p上作用了一次，如果作用两次就是d(d(p))。  
现在给定函数 (M|x:表示M整除x)  
  
  
  
同时给定M，问有多少个数x第一次等于1需要作用N次该函数

## 输入

第一行两个整数M,N。

## 输出

一行一个整数代表答案对10^9+9取模后的值

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1548)

```
5 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1548)

```
4
```

## 提示

四个答案分别是3、20、24、125。

对于30%的数据，N,M<=100;

对于50%的数据, 1<N<=5e4,1=<M<=5e4

对于额外20%的数据,N<=1e6,M=2;

对于100%的数据，1<N<=1e6,1=<M<=1e6;
