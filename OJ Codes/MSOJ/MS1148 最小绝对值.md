# 1148: ****最小绝对值

## 题目描述

已知一个长度为n的不下降子序列，元素可正可服，有可能有重复的元素，现要求出绝对值最小的元素的绝对值的值。

要求：请使用二分查找

## 输入

第一行n，第二行n个数

## 输出

最小绝对值的值

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1148)

```
6
-3 -2 -2 1 3 7
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1148)

```
1
```

## 提示

n<=1000000;
