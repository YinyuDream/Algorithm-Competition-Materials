# 1031: **反向输出一个三位数2

## 题目描述

输入一个三位数，把它反向输出，并且输出格式符合数字规则。比如100，反向输出就是1(即去除多余前导零).

## 输入

一个三位数。

## 输出

反向输出的结果。不含多余前导零。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1031)

```
120
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1031)

```
21
```

## 提示

输入数据范围100=<n<=999
