# 1598: 立方体

## 题目描述

在n维空间中，⼀个单位立方体由2n个点组成。  
他们的坐标形如(x1,x2,...,xn),xi∈{0,1}。  
定义n维空间中两点的距离为其曼哈顿距离,点p(p1,p2,...,pn)与点q(q1,q2,...,qn)的距离为： 。  
现在给你单位立方体上⼀点p以及⼀个整数k，问你与点p距离为 k的单位立方体上点的数量。  
因为这样的点可能很多，所以请对109+7取模。

## 输入

输入共两行。  
第一行两个数字，表示n和k。  
第二行 n 个数字，表示p的坐标。

## 输出

一行一个数字，表示点的数量。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1598)

```
3 2
1 1 0
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1598)

```
3
```

## 提示

距离(1,1,0)为2的点共三个(0,0,0),(0,1,1),(1,0,1)。

对于 30% 的数据，满足n≤15。

对于 60% 的数据，满足n≤103 。

对于 100%的数据，满足1≤k≤n≤106。
