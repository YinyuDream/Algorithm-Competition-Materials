# 1059: ***最大公约数

## 题目描述

给定两个正整数m和n，求m和n的最大公约数。（辗转相除法）

观察：15 27

15 / 27=0...15

27 / 15=1...12

15 / 12=1...3

12 /3 =4..0

所以3就是15和27的最大公约数

## 输入

一行，两个正整数m和n

## 输出

一行，两个数的最大公约数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1059)

```
6 9
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1059)

```
3
```

## 提示

对于60%的数据，m,n<=10000000.

对于100%的数据，m,n<=10000000000
