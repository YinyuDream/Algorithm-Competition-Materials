# 1704: dalao

## 题目描述

初始时滑冰俱乐部有1到n号的溜冰鞋各k双。已知x号脚的人可以穿x到x+d的溜冰鞋。
  

有m次操作，每次包含两个数ri,xi，代表来了xi个ri号脚的人。xi为负，则代表走了这么多人。
  
对于每次操作，输出溜冰鞋是否足够。

## 输入

输入第一行，四个数n,m,k,d，意思如题意
  

接下来m行，每行两个数ri和xi

## 输出

对于每个操作，输出一行，TAK表示够，NIE表示不够。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1704)

```
4 4 2 1
1 3
2 3
3 3
2 -1
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1704)

```
TAK
TAK
NIE
TAK
```

## 提示

对于   30%的数据：1≤n≤200,0 ，m≤500,0
  

对于100%的数据：1≤n≤200,000，1≤m≤500,000，1≤k≤10^9，0≤d≤n，
  
1≤ri≤n-d，|xi|≤10^9
