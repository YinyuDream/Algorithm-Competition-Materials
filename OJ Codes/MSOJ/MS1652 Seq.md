# 1652: Seq

## 题目描述

有一个数字序列，从1开始标号，初始为空。现在给出一些操作，要求维护这个数字序列，操作类型 如下：

1.      在序列末尾添加数字c

2.      撤销最近的p个1类和2类操作

3.      询问当前序列第q个数字。

## 输入

第一行一个正整数T，表示数据组数。

对于每组数据，第一行一个正整数n，表示操作个数。

接下来每行两个正整数，第一个数表示操作类型（1,2,3)，第二个数表示参数。

## 输出

输出若干行，按顺序给出每个询问的答案。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1652)

```
1
5
1 2
1 3
3 2
2 1
3 1
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1652)

```
3
2
```

## 提示

n<=200000,T<=5
