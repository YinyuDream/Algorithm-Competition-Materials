# 1230: ****输出第n个数

## 题目描述

已知杨辉三角形，输入一个正整数n，请输出杨辉三角形第n个数是多少。

## 输入

一个数n

## 输出

一个数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1230)

```
20
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1230)

```
5
```

## 提示

n<=1000
