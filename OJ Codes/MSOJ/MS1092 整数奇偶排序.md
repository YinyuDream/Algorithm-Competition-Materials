# 1092: ***整数奇偶排序

## 题目描述

给定n个整数的序列，要求对其重新排序。排序要求:

1.奇数在前，偶数在后；

2.奇数按从大到小排序；

3.偶数按从小到大排序。

## 输入

两行，第一行n，第二行n个数

## 输出

一行，排序后的数列

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1092)

```
10
4 7 3 13 11 12 0 47 34 98
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1092)

```
47 13 11 7 3 0 4 12 34 98
```

## 提示

n<=100,每个数<=10000
