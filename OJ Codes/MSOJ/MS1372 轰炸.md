# 1372: 轰炸

## 题目描述

雷达监测到平面上有n个敌方据点，现在要派出轰炸机轰炸。为了保证轰炸的时效性，我方觉得轰炸机在出发后就不再改变方向，即轰炸的轨迹是一条直线。  
假设飞行员水平足够高超，知道敌方据点在这条直线上就能够轰炸到。现在，指挥官小T想知道一架飞机最多能够轰炸几个地方据点(起点不固定)

## 输入

第一行一个正整数n，表示敌方据点总数；

后面n行，每行两个数，表示一个敌方据点的坐标

## 输出

一个数，表示一架飞机最多能轰炸的地方据点数量

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1372)

```
5
1 1
2 2
3 3
9 10
10 11
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1372)

```
3
```

## 提示

有一架飞机可以轰炸到(1,1),(2,2),(3,3)

对于30%的数据，n<=10;

对于80%的数据，n<=500;

对于100%的数据，n<=1200,|坐标|<=int
