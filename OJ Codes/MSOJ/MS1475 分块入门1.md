# 1475: 分块入门1

## 题目描述

给出一个长为 n的数列，以及 n个操作，操作涉及区间加法，单点查值。

## 输入

第一行输入一个数字n。  
第二行输入n个数字，第i个数字为ai，以空格隔开。  
接下来输入n行询问，每行输入四个数字opt、l、r、c，以空格隔开。  
若opt=0，表示将位于[l,r] 的之间的数字都加 c。  
若opt=1，表示询问ar的值（l 和 c 忽略）。

## 输出

对于每次询问，输出一行一个数字表示答案。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1475)

```
4
1 2 2 3
0 1 3 1
1 0 1 0
0 1 2 2
1 0 2 0
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1475)

```
2
5
```

## 提示

对于100%的数据，1≤n≤50000,-2^31<=other,ans≤2^31-1。
