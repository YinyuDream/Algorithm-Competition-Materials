# 1190: **表达式求值1

## 题目描述

给定一个只包含加号和减号的算术表达式，并且数字都是个位数，并且没有负数，请你编程计算表达式的值。

## 输入

一行表达式

## 输出

表达式的结果

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1190)

```
1+2-4-6+3-1-2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1190)

```
-7
```

## 提示

字符串长度<=1000;
