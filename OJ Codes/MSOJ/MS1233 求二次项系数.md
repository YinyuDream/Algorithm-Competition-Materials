# 1233: ***求二次项系数

## 题目描述

给定一个多项式(x+y)k，求出x^n\*y^m的系数(n+m=k).

## 输入

输入两个数，n和m。

## 输出

一个结果

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1233)

```
2 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1233)

```
10
```

## 提示

n,m<=20
