# 1335: 区间第k大

## 题目描述

一个区间的价值定义为该区间中的最大值减最小值.现给定n个数，求所有区间价值中，第 k 大值为多少。

## 输入

第一行两个数n和k(k<=n\*(n-1)/2)  
第二行n个数，每个数<=109

## 输出

输出区间价值的第k大值

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1335)

```
3 2
2 1 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1335)

```
2
```

## 提示

[l,r]表示第l个数到r个数组成的区间的价值

[1,1]=0 [1,2]=1 [1,3]=2

[2,2]=0 [2,3]=2

[3,3]=0;

对于30%的数据，n<=500;

对于60%的数据，n<=5000;

对于额外10%的数据，n<=400000，k=1;

对于100%的数据，n<=400000,
