# 1133: #区间最大值

## 题目描述

已知一个长度为n的正整数（ai<=10000）序列，现要求出：一段区间的最小值\*该区间内的所有数之和 的值最大。请输出最大的值是多少以及区间的起点和终点位置。

## 输入

第一行n，第二行n个数

## 输出

第一行最大值  
第二行最大值所对应的区间的起点和终点位置，中间用一个空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1133)

```
5
1 6 4 5 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1133)

```
60
2 4
```

## 提示

样例解释：

4\*（6+4+5）=60

数据范围  
对于30%的数据   n<=100;  
对于60%的数据   n<=5000;  
对于100%的数据  n<=100000;
