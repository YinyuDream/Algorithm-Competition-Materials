# 1147: *****二分查找4

## 题目描述

一个长度为n的有序不下降序列，给定m次查找，输出查找的数在序列中出现的次数，如果没有出现过，输出0.

## 输入

四行，第一行n，第二行n个数，第三行m，第四行m个数

## 输出

m行结果，表示出现的次数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1147)

```
6
1 3 3 3 7 9
3
1 3 8
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1147)

```
1
3
0
```

## 提示

n<=1000000,m<=10000;
