# 1072: 排序2

## 题目描述

给你n个整数，请按从大到小的顺序输出其中前m大的数。

## 输入

第一行有两个数n,m

接下来一行，用空格隔开的n个数

## 输出

对测试数据按从大到小的顺序输出前m大的数。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1072)

```
5 2
-207693 190069 13569 -48891 -354975
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1072)

```
190069 13569
```

## 提示

对于100%的数据：n<=1000000;
