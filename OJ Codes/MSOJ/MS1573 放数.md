# 1573: 放数

## 题目描述

两种操作：  
1:加入一个数x。  
2:询问有多少个数是x的倍数。

## 输入

第一行一个整数N，代表操作数量。              
接下来N行，每行两个数opt,x。其中opt表示是哪种操作，第二个x是操作的参数。

## 输出

一行一个整数，代表所有询问答案的异或值。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1573)

```
5
1 2
1 3
2 2
1 6
2 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1573)

```
3
```

## 提示

对于30%的数据，N<=3000;

对于额外15的数据,N<=50000,插入数的种类<=1000;

对于额外15%的数据，N<=50000，x<=1000。

对于100%的数据，N<=50000,x<=1000000。
