# 1221: **走台阶2

## 题目描述

简单的走台阶问题我们已经会了，还是每次可以走一步，可以走两步。我们这次改变一下策略，如果台阶中某些台阶坏掉了是不可以走的，那请问走到台阶n有多少种方案。输入n，再输入n个数，分别表示该层台阶的状态，0表示可以走，1表示不可以走。求方案数，仍然是让结果对10000003取余

## 输入

两行，第一行n，n<=1000,第二行n步台阶的状态，用0和1表示

## 输出

方案数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1221)

```
6
0 0 1 0 0 0
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1221)

```
4
```
