# 1389: 乘船问题

## 题目描述

有 n 个人需要过河，但是河上没有桥，只能通过乘小船的方式过去。

已知每个人的重量 w[i]，并且每搜小船的载重量都是相同的，均为 m，由于小船的空间有限，每次最多只能乘坐两人。问如何用最少的船装载所有人过河，最少数量为多少。如果小船没有办法把所有人都送过去，输出”no way”

## 输入

第一行两个数， n 和 m，分别表示人数和船的载重量  
第二行 n 个数，分别表示每个人的重量 w[i]。

## 输出

最少需要的小船数量

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1389)

```
3 5
2 4 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1389)

```
2
```

## 提示

对于 30%的数据， n<=10,m<=int,w[i]<=int;  
对于 100%的数据， n<=1000000,m,w[i]<=int;
