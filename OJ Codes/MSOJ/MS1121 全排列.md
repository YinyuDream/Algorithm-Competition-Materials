# 1121: **全排列

## 题目描述

求出1--n这n个数的全排列的种数

## 输入

n个数

## 输出

方案数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1121)

```
4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1121)

```
24
```

## 提示

n<=10
