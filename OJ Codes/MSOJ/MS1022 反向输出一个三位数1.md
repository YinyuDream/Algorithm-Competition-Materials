# 1022: 反向输出一个三位数1

## 题目描述

将一个三位数反向输出。

## 输入

一个三位数n。

## 输出

反向输出n。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1022)

```
100
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1022)

```
001
```

## 提示

对于100的数据：100<=n<=999
