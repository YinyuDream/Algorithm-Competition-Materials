# 1109: ***稀疏矩阵

## 题目描述

大部分元素是0的矩阵称为稀疏矩阵，假设有k个非零元素，则可把习俗矩阵用k\*3的矩阵简记之，其中第一列是行号，第二列是列号，第三列是改行、该列下的非零元素的值。多组数据按照先行后列的排列顺序。如果一个矩阵中全是0，那么输出0.

## 输入

第一行n，m，后面一个n\*m的矩阵。

## 输出

很多行，所有非零元素的行 列 值
  

行号 列号 值、
  

每个之间换行

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1109)

```
3 4
0 0 0 5
0 2 6 0
0 1 0 0
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1109)

```
1 4 5
2 2 2
2 3 6
3 2 1
```

## 提示

第1行第4列是非零元素5
  

第2行第2列是非零元素2
  

第2行第3列是非零元素6
  

第3行第2列是非零元素1
  

n,m<=100
