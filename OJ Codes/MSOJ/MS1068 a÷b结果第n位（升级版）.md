# 1068: ****a÷b结果第n位（升级版）

## 题目描述

计算a÷b结果第n位上的数字是多少(小数点不算位数),a÷b表示a除以b的准确结果

## 输入

一行，a,b,n三个正整数

## 输出

一行

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1068)

```
200 7 6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1068)

```
4
```

## 提示

a,b,n<=100000
