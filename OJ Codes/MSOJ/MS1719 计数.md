# 1719: 计数

## 题目描述

小 A 是一名热衷于优化各种算法的 OIER,有一天他给了你一个随机生成的 1~n 的排列a，并定义区间[l,r]的价值为：
  

**C(l,r)=max(a[i]-a[j])(l<=i,j<=r)**
  

他想请你告诉他， 所有区间的价值的总和为多少

## 输入

第一行一个数 T(<=10)， 表示数据组数
  

对于每一组数据：
  

第一行一个数 n（1<=n,m<=100,000）
  

第二行 n 个数 a1...an， 表示一个 1~n 的随机的排列

## 输出

对于每组数据输出一个数， 表示答案

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1719)

```
1
4
3 2 4 1
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1719)

```
14
```

## 提示

对于30%的数据，n<=200;
  

对于50%的数据，n<=1000;
  

对于70%的数据，n<=20000;
  

对于100%的数据，n<=100000。
