# 1243: ****斐波拉契数列数列(高精度)

## 题目描述

已知斐波那契数列第一项为1，第二项为1，求斐波那契数列第n项是多少，由于n可能很大，所以结果会超出long long 的范围,所以需要高精度

## 输入

一个数字n

## 输出

一个结果

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1243)

```
5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1243)

```
5
```

## 提示

n<=1000;
