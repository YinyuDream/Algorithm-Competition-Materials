# 1111: ***前缀和

## 题目描述

输入一个长度为n的整型数列，先给出m次查询k，k表示数列中前k个数之和，并且输出结果。

## 输入

第一行n，第二行n个数，第三行m，第四行m个数

## 输出

m行，每行一个结果

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1111)

```
6
1 2 3 4 5 6
3
2 4 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1111)

```
3
10
15
```

## 提示

n<=100000,m<=200000
