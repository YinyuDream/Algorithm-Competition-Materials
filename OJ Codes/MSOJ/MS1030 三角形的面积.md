# 1030: *三角形的面积

## 题目描述

输入三角形底边长度和底边上的高，求三角形的面积。已知三角形底边长度和高都是正整数，并且每个数小于等于100。结果保留一位小数。

## 输入

一行，两个正整数。

## 输出

一个结果，表示三角形的面积

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1030)

```
3 4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1030)

```
6.0
```

## 提示

%d:输出格式为整数

%lf：表示输出格式为浮点数（小数）

%.2lf:表示输出保留两位小数的浮点数（小数）

%.5lf：输出保留五位小数的浮点数（小数）
