# 1435: 第k小的数

## 题目描述

有两个正整数数列,元素个数分别为 N 和 M。从两个数列中分别任取一个数相乘,这样一共可以得到 N\*M 个数。

询问这 N\*M 个数中第 K 小数是多少。保证K合理

## 输入

第一行为三个正整数 N,M 和 K。

第二行为 N 个正整数,表示第一个数列。每个数<=int

第三行为 M 个正整数,表示第二个数列。每个数<=int

## 输出

输出文件包含一行,一个正整数表示第 K 小数。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1435)

```
2 3 4
1 2
2 1 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1435)

```
3
```

## 提示

对于 30%的数据，N,M,K<=1000

对于 60%的数据，N,M,K<=100000

对于 100%的数据，N,M<=200000,K<=1e9
