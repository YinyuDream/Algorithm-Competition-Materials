# 1578: 树变环

## 题目描述

树是个好东西，删掉树一条边要1的代价，随便再加一条边有1的代价，求最小的代价把一棵树变成一个环(所有点都在环上)

## 输入

第一行一个整数N，代表树的点数。

接下来N-1行，每行两个数代表树的一条边。

## 输出

一行一个整数代表答案。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1578)

```
4
1 2
2 3
2 4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1578)

```
3
```

## 提示

删除边(1,2),连接(1,3)和(1,4)。

对于 30% 数据，1≤N≤10  
对于 50% 数据，1≤N≤1000  
对于 70%数据，1≤N≤100000  
对于额外10%的数据，保证数据为一条链;  
对于100%的数据，1<=N<=2000000。
