# 1056: *n个数的和与均值

## 题目描述

输入n个整数，求出n个数的和与平均值

## 输入

两行，第一行输入个数n，第二行为n个输入的数

## 输出

一行两个数，分别表示和与均值，每个数之间用空格隔开，均值保留两位小数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1056)

```
4
344 222 343 222
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1056)

```
1131 282.75
```

## 提示

n<=100000,每个数的绝对值小于100000
