# 1038: *X的倍数

## 题目描述

输入两整数，x和y，请判断x是否是y的倍数。如果是请输出YES，否则输出NO

## 输入

输入共一行，用空格隔开的两个数x和y。

## 输出

输出共一行，YES或者NO

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1038)

```
56 8
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1038)

```
YES
```

## 提示

对于100%的数据：x,y<=109
