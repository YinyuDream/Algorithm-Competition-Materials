# 1119: 进制转换

## 题目描述

把任意一个N进制数K转换成对应的M进制数（M,N均小于10)。
  

输入三个数，n,m,k,表示的含义把n进制数k转换成对应的m进制数。

## 输入

输入共一行，n,m,k。意思如题目所示

## 输出

输出一个数，所对应的M进制数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1119)

```
10 2 12
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1119)

```
1100
```

## 提示

对于100%的数据：2<=n,m<=16，k<=109
  
如果进制＞10，则10用'A'表示，11用'B'表示，12用'C'表示，13用'D'表示，14用'E'表示，15用'F'表示。
