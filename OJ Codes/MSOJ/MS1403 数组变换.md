# 1403: 数组变换

## 题目描述

你的面前有一个长度为 n 的数组。初始时，第 i个位置的元素为 i（即所有位置上的元素依次为从 1 到 n的正整数）。  
接下来，你需要帮我依次完成m 个操作。每个操作可能是：  
A p q，表示你需要修改数组中的所有元素。具体地，第 i个位置的元素被修改成 p×i+q。  
B x y，表示你需要修改数组中的单个元素。具体地，第 x个位置的元素被修改成y。  
其中上述p,q,x,y 均为整数，每次操作结束后，你需要输出数组中所有元素的和。

## 输入

第一行包含两个数 n,m。

接下来m行，每行依次表示一个操作，格式为A p q或者B x y，意义如上所述。

## 输出

输出共 m 行，每行表示每个操作结束后，数组中所有数的和。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1403)

```
5 4
B 1 5
A -1 0
A 1 2
A 2 -5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1403)

```
19
-15
25
5
```

## 提示

第1次操作结束后，数组变为{5, 2, 3, 4, 5}；

第2次操作结束后，数组变为{-1, -2, -3, -4, -5}；

第3次操作结束后，数组变为{3, 4, 5, 6, 7}；

第4次操作结束后，数组变为{-3, -1, 1, 3, 5}。

对于30%的数据，n<=100;

对于额外20%的数据，n<=5e7,m<=5e5,所有操作均为B类型

对于额外20%的数据，n<=5e7,m<=5e5,所有操作均为A类型

对于100%的数据，n<=5e7,m<=5e5,|p|<=1000,|q|,|y|<=1e9,1<=x<=n
