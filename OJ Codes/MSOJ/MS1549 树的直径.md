# 1549: 树的直径

## 题目描述

小Y刚学完如何求解树的直径，为了巩固自己对树的理解，小Y画了一颗结点数为N的超级大的树，突然，他想到了老师上课讲的树的直径的问题。  
他想知道，如果删去K条边，把树分成K+1个联通块，所有联通块中最长的直径长度最小是多少  
此处树的直径长度指树上最长简单路径的长度  
为了防止递归过深爆栈，加入编译命令 –Wl,--stack=10000000

## 输入

第一行两个整数N,K,分别表示树的大小和删除的边数

后面N-1行，每行两个数u,v表示树的一条边

## 输出

一行一个整数，表示所有删去K条边的情况，所有联通块的最长直径的最小值

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1549)

```
6 2
1 2
1 3
1 4
2 5
3 6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1549)

```
1
```

## 提示

删去(1,2),(1,3)两条边后，剩下的部分均为两个点连在一起，其中最长路径长度均为1.

对于30%的数据,N,K<=30;

对于50%的数据,N,K<=50000;

对于额外10%的数据,N<=400000,K=0,

对于额外10%的数据,N<=400000,保证数据为一条链

对于100%的数据,N<=400000,K<=N-1.
