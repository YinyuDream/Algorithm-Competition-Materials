# 1039: **三角形的判断

## 题目描述

输入三角形的三边a,b,c,判断输入的三边能组成什么样的三角形，三角形的类型如下：

1、等边三角形

2、一般等腰三角形

3、等腰直角三角形

4、一般直角三角形

5、一般三角形

6、不能构成三角形

## 输入

输入共一行，用空格隔开的三个整数a,b,c,表示三角形的三边

## 输出

输出共一行，一个数字1--6，表示三角形的类型

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1039)

```
3 4 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1039)

```
4
```

## 提示

对于100%的数据：a,b,c<=10000。
