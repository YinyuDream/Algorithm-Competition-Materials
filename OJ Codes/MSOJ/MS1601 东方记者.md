# 1601: 东方记者

## 题目描述

射命丸文是鸦天狗， 在幻想乡出现之初就存在了， 拥有操纵风的能力， 是幻想  

乡中最快的存在， 从事记者的工作。

这一天， 在幻想乡发生了N起大新闻， 第i起大新闻发生在坐标(Xi,Yi)处。 射命  
丸文从坐标(0,0)处出发， 按照新闻发生的时间顺序前往各个新闻发生地收集资料， 最  
后回到坐标(0,0)处。 虽然她的速度很快， 但是她只会横冲直撞， 换句话说， 她的移动  
必须平行于某条坐标轴。 而且她的力量是有限的， 她移动的总距离不能超过D。 所以她  
不得不放弃一些大新闻的资料收集。 请问她最多可以收集多少起大新闻的资料？

## 输入

第一行一个非负整数N， 表示大新闻的数量。  
接下来N行， 每行两个整数Xi和Yi， 表示第i起大新闻发生地的坐标。 按照大新  
闻发生的时间顺序给出各个坐标。  
接下来一行一个非负整数D， 表示她移动的总距离的限制。

## 输出

输出一个整数， 表示她最多能收集多少起大新闻的资料。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1601)

```
3 1
1
2 2
1 1
7
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1601)

```
2
```
