# 1085: ***数组变换(升级版)

## 题目描述

对于一个递增数组a，元素个数为n，输入一个数据x，如果x存在于数组a，则把x元素删除；否则将x插在相应的位置，要求数组仍然递增，然后依次输出新的数组元素。

## 输入

第一行一个整数n，第二行为依次递增的n个元素，第三行为一个数字x。

## 输出

新的数组元素。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1085)

```
5
10 23 34 53 83 
34
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1085)

```
10 23 53 83
```

## 提示

数组为整数数组，n<=10000
