# 1042: *判断数正负

## 题目描述

给定一个整数N，判断其正负。

## 输入

一个整数N(-109 <= N <= 109)

## 输出

如果N > 0, 输出positive;  
如果N = 0, 输出zero;  
如果N < 0, 输出negative

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1042)

```
1
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1042)

```
positive
```

## 提示

对于100%的数据：(-109 <= N <= 109)
