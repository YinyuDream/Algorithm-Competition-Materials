# 1064: **满足条件的数之和

## 题目描述

将正整数 m 和 n 之间(包括 m,n)能被 17 整除的数累加。输入 m,n，输出满足条件的数之和

## 输入

一行，两个数，m,n

## 输出

一行，一个数，和

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1064)

```
2 67
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1064)

```
102
```

## 提示

0=<m<=n<=1000
