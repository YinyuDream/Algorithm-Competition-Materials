# 1429: 排列

## 题目描述

已知关于n的排列是有顺序的n个数，每个数为1到n且1到n中每个数出现且仅出现一次。  
现在，小T把一些排列混在了一起(也可能混入了一些别的数)，他想让你把排列全部划分开。小T给了你一个n个数的序列，你需要判断这些书是否是若干个排列组成的，如果是，你需要先输出排列个数，再输出每个数属于哪个排列。  
为了减(zeng)小(jia)难度，在输出每个数属于哪个排列，小T想让你用最小字典序输出。字典序的比较，即先比较第一个数属于排列的大小，再比较第二个数….

## 输入

第一行输入n，表示有n个数  
接下来一行，共n个数，描述这个序列

## 输出

如果是由若干个排列组成，第一行输出排列的个数，第二行n个数，表示每个数属于哪个排列(注意要求最小字典序)，否则输出-1。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1429)

```
9
1 2 3 1 2 1 4 2 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1429)

```
3
1 1 1 2 2 3 1 3 1
```

## 提示

对于30%的数据，n<=10  
对于60%的数据，n<=1000  
对于100%的数据，n<=100000,序列中数<=n;
