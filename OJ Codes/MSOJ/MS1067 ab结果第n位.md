# 1067: **a/b结果第n位

## 题目描述

计算a/b结果第n位是多少,a,b,n都是正整数，(a/b表示整除)

## 输入

一行，三个数，a,b,n

## 输出

一行，一个结果

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1067)

```
23 3 1
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1067)

```
7
```

## 提示

a,b,n<=10000000,并且n小于等于a/b的位数
