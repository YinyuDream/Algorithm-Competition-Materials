# 1697: 树

## 题目描述

给定一棵大小为
n 的有根点权树,支持以下操作:
  

• 换根
  

• 修改点权
  

• 查询子树最小值

## 输入

第一行两个整数n,
Q ,分别表示树的大小和操作数。 
  

接下来n行,每行两个整数f,v,第i+1行的两个数表示点i的父亲和点i的权。保证f < i。如果f = 0,那么i为根。输入数据保证只有i = 1时,f = 0。   
  接下来m行,为以下格式中的一种:   
  • V x y表示把点x的权改为y   
  • E x 表示把有根树的根改为点x   
  • Q x 表示查询点x的子树最小值

## 输出

对于每个Q
,输出子树最小值。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1697)

```
3 7
0 1
1 2
1 3
Q 1
V 1 6
Q 1
V 2 5
Q 1
V 3 4
Q 1
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1697)

```
1
2
3
4
```

## 提示

对于20%的数据，n,q<=2000;  
对于额外10%的数据，n,q<=20000,其中E操作数<=1000;  
对于额外20%的数据，n,q<=100000,其中无E操作。  
对于额外20%的数据，n,q<=100000,其中无V操作。  
对于100%的数据，n,q<=100000,点权<=int
