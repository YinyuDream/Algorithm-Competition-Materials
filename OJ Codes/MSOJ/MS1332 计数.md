# 1332: 计数

## 题目描述

给出 m 个数 a[1],a[2],…,a[m]  
求 1~n 中有多少数不是 a[1],a[2],…,a[m]的倍数。

## 输入

输入文件名为 count.in。  
第一行，包含两个整数：n,m  
第二行，包含 m 个数，表示 a[1],a[2],…,a[m]

## 输出

输出文件名为 count.out。  
输出一行，包含 1 个整数，表示答案

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1332)

```
10 2
2 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1332)

```
3
```

## 提示

对于 60%的数据，1<=n<=106  
对于另外 20%的数据，m=2  
对于 100%的数据，1<=n<=10^9,0<m<=20,1<=a[i]<=10^9
