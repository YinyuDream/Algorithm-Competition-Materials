# 1070: ***第n小的质数

## 题目描述

输入一个正整数n，求第n小的质数.n<=10000.

## 输入

一行，一个正整数n

## 输出

一行，第n小的质数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1070)

```
5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1070)

```
11
```

## 提示

n<=1000
