# 1089: ***求第k大的值

## 题目描述

输入n个数，求n个数里面第k大的数

## 输入

三行，第一行n，第二行n个数，第三行k

## 输出

一个数，第k大的数，确保k<=n

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1089)

```
5
1 2 3 5 4
2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1089)

```
4
```

## 提示

n<=100000,k<=1000;
