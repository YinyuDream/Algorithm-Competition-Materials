# 1135: ****多次查找

## 题目描述

已知一个长度为n的递增序列（严格递增）,现给定次查找，判断每次查找的x是否在序列中出现过，如果出现过，则输出在序列中出现的位置，如果没有出现过，则输出“No Number”。

## 输入

第一行n，第二行n个数，第三行查找的次数m,第4行表示m次查找

## 输出

查找的结果，如果出现过，输出出现的位置，如果没有出现过，输出“No Number”；

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1135)

```
4
1 3 5 7
3
7 3 0
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1135)

```
4
2
No Number
```

## 提示

提示  
n<=100000,m<=100000;
