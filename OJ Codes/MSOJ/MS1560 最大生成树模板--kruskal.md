# 1560: 最大生成树模板--kruskal

## 题目描述

给出一个无向图，求该无向图的最大生成树，保证图连通

## 输入

第一行两个数N,M表示图的点数和边数

后面M行每行三个数表示一条边.

## 输出

输出一个数，表示最大生成树各边之和

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1560)

```
3 3
1 2 1
2 3 3
3 1 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1560)

```
5
```

## 提示

对于100%的数据,N,M<=100000,|W|<=int
