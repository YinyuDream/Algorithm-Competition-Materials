# 1182: ***成绩排序

## 题目描述

期中考试之后，老师要根据每个同学的成绩对全校所有的学生进行排序，已知一个学生有如下信息：姓名(拼音，不超过20个字符)，学号，性别（F表示女生，M表示男生）,语文，数学，英语成绩(全是整数)。请计算出总成绩和平均分，平均分保留一位有效数，并且排序如果成绩相同按照学号排序。请写出程序.

## 输入

第一行n表示n个学生，后面n行每个学生的信息，依次为姓名，学号，性别，语文成绩，数学成绩，英语成绩。

## 输出

n个总分由高到低排好序的学生，每个学生信息包括姓名，学号，性别，语文成绩，数学成绩，英语成绩，总成绩和平均分,每个信息用空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1182)

```
4
Xiaoming 2 M 87 92 90
Xiaohong 3 F 91 94 93
Xiaodong 1 M 90 97 86
Xiaofang 5 F 89 91 93
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1182)

```
Xiaohong 3 F 91 94 93 278 92.7
Xiaodong 1 M 90 97 86 273 91.0
Xiaofang 5 F 89 91 93 273 91.0
Xiaoming 2 M 87 92 90 269 89.7
```

## 提示

n<=1000.
