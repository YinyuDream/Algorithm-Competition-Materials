# 1609: アスヨゾラ哨戒班

## 题目描述

少女从夜空坠落。
  

繁星满天。
  

少女愉快地数起了星星。
  

由于少女要做落地的准备，所以她只有时间数一条直线上的星星。
  

直线上有N个星星，每颗星星都是忽明忽暗的，所以它们有最小和最大的亮度。星星在少女刚刚开始观察时都是最大或最小亮度，每个单位时间星星亮度的变化都是1。在星星到最小亮度时，下一时刻亮度就会上升；在星星到最大亮度时，下一时刻亮度就会下降。
  

少女想知道在u时刻区间[l,r]中星星的亮度之和或星星亮度的最大值

## 输入

第一行两个数N,M，星星和询问的个数。
  

接下来N行，每行四个整数 pi,mni ,mxi,numi,表示第i颗星星的坐标，最小和最大亮度,初始状态。numi=0表示开始时为最小亮度,numi=1表示开始时为最大亮度。
  

接下来m行，每行四个数opi,ti,li ,ri，表示第i个询问的类型opi，时刻ti。opi=0表示询问在时刻ti区间[li,ri]内星星的亮度和；opi=1表示询问在时刻ti区间[li,ri]内星星亮度的最大值。

## 输出

接下来m行每行一个数，表示询问的答案。若区间[l,r]中没有星星,输出−1。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1609)

```
4 2
1 1 1 0
3 3 5 0
4 4 4 0
2 2 4 0
0 1 1 4
0 2 0 1000000000
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1609)

```
12
14
```

## 提示

数据保证0≤mni ,mxi,li,ri,ti,|pi|≤109,mni≤mxi，li≤ri，没有p相同。
