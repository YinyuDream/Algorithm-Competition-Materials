# 1079: ***方程解组数

## 题目描述

给定正整数a,b,c，求不定方程ax+by=c关于未知数x和y的所有非负整数解的组数有n组。

## 输入

一行，三个数,a,b,c

## 输出

一个结果，解的组数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1079)

```
1 2 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1079)

```
2
```
