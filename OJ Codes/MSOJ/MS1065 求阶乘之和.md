# 1065: ***求阶乘之和

## 题目描述

S = 1 ! + 2 ! + 3 ! + … n ! ，输入 n，求 S：(!表示阶乘，5！=5\*4\*3\*2\*1)

## 输入

一行，n以内的阶乘之和

## 输出

一行，阶乘之和s

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1065)

```
5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1065)

```
153
```

## 提示

n<=15
