# 1222: ***走台阶3

## 题目描述

有N级的台阶，你一开始在底部，每次可以向上迈最多K级台阶（最少1级），问到达第N级台阶有多少种不同方式。

## 输入

输入文件的仅包含两个正整数N，K。

## 输出

仅包括1个正整数，为不同方式数，由于答案可能很大，你需要输出mod 100003后的结果。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1222)

```
5 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1222)

```
8
```

## 提示

对于20%的数据,有N ≤ 10, K ≤ 3;

对于40%的数据，有N ≤ 1000;

对于100%的数据，有N ≤ 100000，K ≤ 100。

注意，该题无测试数据，测试请到

<https://www.luogu.org/problemnew/show/P1192>
