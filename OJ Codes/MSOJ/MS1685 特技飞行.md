# 1685: 特技飞行

## 题目描述

神犇航空开展了一项载客特技飞行业务。每次飞行长 n 个单位时间，每个单位时间可以进行一项特技动作，可选的动作有 k 种，每种动作有一个刺激程度 ci。如果连续进行相同的动作，乘客会感到厌倦，所以定义某次动作的价值为(距上次该动作的时间)×ci，若为第一次进行该动作，价值为 0。安排一种方案，使得总价值最大。

## 输入

第一行，两个整数，n 和 k，如上所述；
  

第二行，k 个整数，表示 k 种动作的 ci 值。

## 输出

仅一行，一个整数，表示最大总价值。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1685)

```
5 2
2 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1685)

```
12
```

## 提示

对于10% 的测试数据，n≤20，k≤3。
  

对于100% 的测试数据，1≤n≤10^3，1≤k≤300，0≤ci≤10^3。
