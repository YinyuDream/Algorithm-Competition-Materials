# 1106: **矩阵最大值

## 题目描述

输入一个n\*m的矩阵，求该矩阵中最大的元素和最小的元素，分别输出最大元素的行列和最小元素的行列号,如果有多个，输出行号最小的那一个，如果行号相同，输出列号最小的那一个。

## 输入

第一行，n和m，后面n行每行m个数

## 输出

两行，第一行最大值的行列号，第二行最大值得行列号，分别用空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1106)

```
3 3
1 2 3
3 4 7
5 6 8
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1106)

```
3 3
1 1
```

## 提示

n,m<=100
