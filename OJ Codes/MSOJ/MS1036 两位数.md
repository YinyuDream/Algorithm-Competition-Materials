# 1036: *两位数

## 题目描述

输入一个整数，判断这个整数是否是两位数，是用“Yes”表示，不是用“No”表示

## 输入

一行，一个整数

## 输出

一行，结果，“Yes”或者“No”。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1036)

```
23
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1036)

```
Yes
```
