# 1241: ****数字三角形(超级版)

## 题目描述

数字三角形必须经过某一个点，使之走的路程和最大

## 输入

第1行n，表示n行

第2到n+1行为每个的权值

第n+2行为两个数x,y表示必须经过的点

## 输出

最大值

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1241)

```
2
1
1 1
1 1
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1241)

```
2
```

## 提示

n<=100,每个数<=1000
