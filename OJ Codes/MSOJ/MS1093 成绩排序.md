# 1093: **成绩排序

## 题目描述

n个同学参加考试，每个同学有一个成绩(假设每个同学的成绩各不相同),并且每个同学有一个学号，按照成绩由高到低对每位同学排序。

## 输入

n+1行，第一行n，第2--n+1行分别为每位同学的学号和成绩。均为整数

## 输出

n行，每行为学号和成绩，用空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1093)

```
4
1 90
2 78
3 45
4 97
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1093)

```
4 97
1 90
2 78
3 45
```

## 提示

n<=5000
