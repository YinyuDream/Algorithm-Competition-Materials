# 1150: *****查找

## 题目描述

已知一个长度为n的无序数列，先给定m次查找，判断需要查找的数在序列中出现的位置，如果没有出现过，输出-1,如果出现过，输出出现的位置

## 输入

第一行n，第二行n个数表示序列，第三行m，第四行m个数表示查找的数

## 输出

m行，出现的位置

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1150)

```
4
4 2 1 6
3
2 5 7
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1150)

```
2
-1 
-1
```

## 提示

n<=100000.m<=100000.
