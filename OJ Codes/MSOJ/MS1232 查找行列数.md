# 1232: ****查找行列数

## 题目描述

输入一个数n，查找第n个数在杨辉三角形的哪一行哪一列

## 输入

一个数n

## 输出

两个数，分别表示行列，中间用空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1232)

```
7
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1232)

```
4 1
```

## 提示

n<=1000000.
