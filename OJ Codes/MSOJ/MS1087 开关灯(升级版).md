# 1087: ***开关灯(升级版)

## 题目描述

有N个灯放在一排，从1到N依次顺序编号。有M个人也从1到M依次编号。1号将灯全部关闭，2将凡是2的倍数的灯打开；3号将凡是3的倍数的灯作相反处理（该灯如为打开的，则将它关闭；如关闭的，则将它打开）。以后的人都和3号一样，将凡是自己编号的倍数的灯作相反处理。

请问：当第M个人操作之后，哪几盏灯是关闭的，按从小到大输出其编号，其间用逗号（英文）间隔.

## 输入

一行，两个数，n,m

## 输出

很多数,每个数之间用,（英文）隔开，最后一个数之后没有,

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1087)

```
10 10
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1087)

```
1,4,9
```

## 提示

n<=100000,m<=100000,
