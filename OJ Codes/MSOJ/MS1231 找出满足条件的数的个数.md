# 1231: ****找出满足条件的数的个数

## 题目描述

找出杨辉三角形前n个数中，有多少个数是k的倍数。(k>=1)

## 输入

一行，两个数n，k。

## 输出

个数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1231)

```
10 1
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1231)

```
10
```

## 提示

n<=100000,k<=1000
