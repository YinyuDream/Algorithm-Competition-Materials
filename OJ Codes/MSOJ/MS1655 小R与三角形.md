# 1655: 小R与三角形

## 题目描述

小 R 所在的小镇有 n 个村落，这 n 个村落分布在一个圆周上，这些村落之  
间两两有直达的小路，小路可能相交，但不存在三条路交于一点。现在小 R 正好  
放暑假了，每天都在村落间游荡。一天，他发现可以从一个非村落的点出发， 在  
不经过村落的情况下经过三条小路再回到这个点。于是他很好奇，一共有多少个  
这样的回路呢？

## 输入

第一行一个正整数 n，含义如上。

## 输出

第一行一个正整数，表示回路的个数。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1655)

```
6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1655)

```
1
```

## 提示

对于 50%的数据，有 n<=20。  
对于 100%的数据，有 n<=100。
