# 1149: ***快速排序

## 题目描述

输入一个长度为n的整数序列，要求按照从小到大的顺序排序，输出排序之后的结果。（没有太多重复的数）

## 输入

第一行n，第二行n个数

## 输出

排序后的数列

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1149)

```
5
2 4 1 6 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1149)

```
1 2 3 4 6
```

## 提示

n<=100000;
