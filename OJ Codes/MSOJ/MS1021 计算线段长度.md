# 1021: 计算线段长度

## 题目描述

已知线段的两个端点的坐标A（Xa,Ya），B（Xb，Yb），求线段AB的长度。

## 输入

共两行。  
第一行是两个实数Xa，Ya，即A的坐标。  
第二行是两个实数Xb，Yb，即B的坐标。  
输入中所有实数的绝对值均不超过10000。

## 输出

一个实数，即线段AB的长度，保留到小数点后3位。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1021)

```
1 1
2 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1021)

```
1.414
```
