# 1066: ****小数点后第n位

## 题目描述

分数a/b化为小数后，求出小数点后第n位数字是多少？

## 输入

一行，三个数，a,b,n，均为正整数

## 输出

一行，小数点后第n位数字

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1066)

```
2 7 6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1066)

```
4
```

## 提示

a,b,n<=10000,a,b,n为正整数
