# 1642: 小 R 与群山

## 题目描述

小 R 成为了新任镇长， 决定对小镇北面的山峰进行改造。 小镇北面有 N 座山， 这些山的高度在 0～9 之间， 从左到右依次编号为 1， …， N， 其高度hi排列成数A。 每座山的维修代价是山的高度,小R想移走一部分山后，使剩下维修代价排列成数A的值最小。

而小镇的财力有限， 最多能移走 S 座山。 小 R 一时不知道该怎么办， 你能帮他设计一下移山方案吗？

## 输入

共一行两个正整数 A 和 S。

## 输出

一个正整数， 表示未移走的山从左到右的高度排列成的整数（前导零不输出）。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1642)

```
178534 4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1642)

```
13
```

## 提示

测试点编号  N  S    
1， 2  <=20  S<=N    
3， 4  <=10^6  S=N-1    
5， 6  <=100  S<=N    
7， 8  <=1000  S<=N    
9， 10  <=10^6  S<=N
