# 1076: ***数字统计

## 题目描述

给定m,n，统计m-n之间（包括m，n）的所有整数中，x出现的次数。比如22中2出现了两次

## 输入

一行，三个数，m,n,x

## 输出

一个数，x出现的次数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1076)

```
2 22 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1076)

```
6
```

## 提示

0<m<=n<10000,0<x<10，m,n,x为正整数
