# 1198: ***迷宫5

## 题目描述

有一个仅由数字0与1组成的n×n格迷宫。你可以从一个位置移动到上下左右的另一个位置。但是相同数字间的移动需要花费代价为1，不同数字间的移动需要花费的代价为2。请问怎么从起点移动到终点花费的代价最少。最少代价是多少？

## 输入

第一行n，后面一个n\*n的矩阵。后一行分别是起点和终点的行列坐标

## 输出

最少代价

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1198)

```
3
0 1 0
0 0 1
1 1 0
1 1 3 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1198)

```
6
```

## 提示

n<=80
