# 1348: 最优序列

## 题目描述

给出一个长度为n(n<=1000) 的整数序列，求一个子序列，使得原序列中任意长度为 m的子串中被选出的元素不超过k(k<=m<=10)个，并且选出的元素之和最大。

## 输入

第一行三个数n,m,k。

第二行n个数，表示各元素数值大小。

## 输出

一个数，表示最大元素和。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1348)

```
10 4 2
7 3 4 8 2 6 5 7 4 8
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1348)

```
36
```

## 提示

对于20%的数据，n <= 10；

对于40%的数据，n <= 100；

对于额外10%的数据，n<=1000,m=k;

对于额外10%的数据，n<=1000,序列呈递增排列;

对于额外10%的数据，n<=1000,序列为正整数  
对于100%的数据，n<=1000,1<=m,k<=10，|序列|<int。
