# 1034: *简单计算

## 题目描述

给定三个整数a,b,c，计算表达式(2a+b)/c的准确结果，结果保留两位小数

## 输入

一行，包括三个整数，a,b,c

## 输出

一个数，保留两位小数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1034)

```
2 3 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1034)

```
1.40
```

## 提示

输入的数<=100
