# 1062: **级数求和

## 题目描述

已知：Sn= 1＋1／2＋1／3＋…＋1／n。显然对于任意一个整数K，当n足够大的时候，Sn大于K。现给出一个整数K（1<=k<=15），要求计算出一个最小的n；使得Sn＞K。

## 输入

一行，一个数K。

## 输出

一行，一个数n

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1062)

```
1
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1062)

```
2
```
