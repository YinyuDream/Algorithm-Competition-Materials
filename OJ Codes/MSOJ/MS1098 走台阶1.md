# 1098: **走台阶1

## 题目描述

小明在走爬楼梯，他一次可以走一步，也可以走两步，请问他如果要达到第n层台阶，她有多少种走法。因为最终的结果可能特别大，所以我们让结果对10000007取余。输出最终的结果

## 输入

一行，n。

## 输出

方案数,

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1098)

```
4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1098)

```
5
```

## 提示

n<=10000;
