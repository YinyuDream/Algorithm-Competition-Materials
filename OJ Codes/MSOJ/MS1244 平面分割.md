# 1244: **平面分割

## 题目描述

求n条直线最多可以把一个平面分割成多少块？例如一条直线可以把一个平面分成两块，两条直线可以把一个平面分成四块。。。。。

## 输入

直线条数n

## 输出

块数m

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1244)

```
3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1244)

```
7
```

## 提示

n<=1000
