# 1567: 摆花

## 题目描述

奇奇是一位辛勤的园丁，他每天的任务就是照顾花园里的各种花花草草，春天到了，花园里百花盛开，五颜六色，前来参观的人络绎不绝，为了让花园整体看上去高端大气上档次，奇奇需要经常调整花园中花的位置，由于花开得很茂盛，并且奇奇的力气也比较小，所以他每次只能交换相邻两盆花的位置，现在奇奇需要随时都知道该花园内连续一段区间内某种颜色的花的数量，花园中花盆的摆放可以看做是一条直线，但是花的数量比较多，奇奇也很忙，所以你能帮助他吗？

## 输入

第一行两个正整数n,m，分别表示花园中花的数量和交换的次数；  
第二行n个数，分别表示每种花的颜色,都为正整数；  
后面m行每行一个操作：  
操作一：1 l r x;询问区间[l,r]里有多少盆颜色为x的花  
操作二：2 k;交换第k和第k+1盆花的位置，k<n。

## 输出

对于每一个操作1，输出一个整数，表示对该询问的答案。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1567)

```
6 5
1 2 3 2 3 3
1 1 3 2
1 4 6 3
2 3
1 1 3 2
1 4 6 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1567)

```
1
2
2 
3
```

## 提示

区间[1,3]里有1盆颜色为2的花；

区间[4,6]里有2盆颜色为3的花；

交换第3和第4盆花的位置，花的序列变为

1 2 2 3 3 3

区间[1,3]里有2盆颜色为2的花

区间[4,6]里有3盆颜色为3的花

对于30%的数据,n,m<=2000;

对于额外10%的数据,n,m<=50000,只有操作1;

对于额外5%的数据,n,m<=50000,花的颜色<=10;

对于65%的数据,n,m<=50000;

对于额外5%的数据,n<=300000,m<=300000,只有操作1;

对于额外5%的数据n<=300000,m<=300000,每种颜色的花数量<=10;

对于100%的数据，n,m<=300000,花的颜色,颜色编号<=n,k<n;
