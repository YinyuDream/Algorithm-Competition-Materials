# 1052: ***三个数排序

## 题目描述

输入三个整数a,b,c，按照从小到大的顺序输出

## 输入

输入共一行，用空格隔开的三个整数a,b,c

## 输出

输出共一行，从小到大的顺序输出三个数a,b,c，每个数之间用空格隔开。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1052)

```
34 65354 64
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1052)

```
34 64 65354
```

## 提示

对于100%的数据：a,b,c<=1031
