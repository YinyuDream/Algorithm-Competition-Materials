# 1518: 序列终结者

## 题目描述

给定一个长度为N的序列，每个序列的元素是一个整数。要支持以下三种操作：

1. 将[L,R]这个区间内的所有数加上V。

2. 将[L,R]这个区间翻转，比如1 2 3 4变成4 3 2 1。

3. 求[L,R]这个区间中的最大值。

最开始所有元素都是0。

## 输入

第一行两个整数N，M。N为序列长度，M为操作个数。   
后面M行，每行最多四个整数，依次为K，L，R，V。K表示是第几种操作，如果不是第1种操作则K后面只有两个数。

## 输出

对于每个第3种操作，给出正确的回答。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1518)

```
4 4
1 1 3 2
1 2 4 -1
2 1 3
3 2 4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1518)

```
2
```

## 提示

对于20%的数据，n,m<=1000

对于额外10%的数据，n,m<=100000,只有操作3;

对于额外10%的数据，n,m<=100000,只有操作1,3；

对于额外20%的数据，n,m<=100000,只有操作2,3；

对于100%的数据，n,m<=100000,无限制
