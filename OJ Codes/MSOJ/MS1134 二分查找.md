# 1134: ***二分查找

## 题目描述

已知一个长度为n的递增序列（严格递增）,现给定一个值x，判断x是否在序列中出现过，如果出现过，则输出在序列中出现的位置，如果没有出现过，则输出“No Number”。

## 输入

第一行n，第二行n个数，第三行查找的值x

## 输出

查找的结果，如果出现过，输出出现的位置，如果没有出现过，输出“No Number”；

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1134)

```
4
1 3 5 7
7
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1134)

```
4
```

## 提示

n<=100000;请使用二分查找
