# 1410: 书信

## 题目描述

1、书信
(letter.pas/c/cpp)

【题目描述】
有 n 个小朋友，编号为 1 到 n，他们每人写了一封信，放到了一个信箱里，接下来每个人从中抽取一封信。显然，这样一共共有 n! 种拿到书信的情况。
现在亮亮规定，对任意的 1<=x,y<=n，如果 x 号小朋友拿到 u 号小朋友写的书信，y 号小朋友拿到 v 号小朋友写的书信，那么(x+y)号小朋友必须拿到(u+v)号小朋友写的书信（这里的加法若和超过了 n，那么就减去 n）。
小林想知道，总共有多少种拿到书信的情况呢？

【输入格式】
只有一行一个正整数 n。

【输出格式】
只有一行一个正整数，表示符合条件的情况的总数。

【样例输入】
2

【样例输出】
1

【样例解释】
只有一种拿法，即两个小朋友都拿自己写的信。

【数据规模】
对于 40% 的数据，n <= 10；
对于 60% 的数据，n <= 10^5；
对于 100% 的数据，1 <= n <= 10^15。

| 数据编号 | n |
| :---: | :---: |
| 1 | <= 10 |
| 2 | <= 10 |
| 3 | <= 10 |
| 4 | <= 10 |
| 5 | <= 10^5 |
| 6 | <= 10^5 |
| 7 | <= 10^15 |
| 8 | <= 10^15 |
| 9 | <= 10^15 |
| 10 | <= 10^15 |
