# 1114: **幂运算

## 题目描述

输入a,n,求a^n的对123456取余的值是多少,a<=1000000,n<=10000;请使用递归求解

## 输入

两个整数a,n;

## 输出

对123456取余的结果

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1114)

```
2 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1114)

```
32
```
