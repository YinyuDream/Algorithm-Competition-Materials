# 1217: *****求m区间内的最小值

## 题目描述

一个含有n项的数列(n<=2000000)，求出每一项前的m个数到它这个区间内的最小值。若前面的数不足m项则从第1个数开始，若前面没有数则输出0。

## 输入

第一行两个数n，m。
  

第二行，n个正整数，为所给定的数列。

## 输出

n行，第i行的一个数ai，为所求序列中第i个数前m个数的最小值。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1217)

```
6 2
7 8 1 4 3 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1217)

```
0
7
7
1
1
3
```

## 提示

对于100% 的数据，保证1≤m≤n≤2×106，1≤ai≤3×107。
