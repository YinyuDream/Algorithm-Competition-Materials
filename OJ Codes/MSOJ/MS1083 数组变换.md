# 1083: **数组变换

## 题目描述

已知一个含n个元素的数组，在数组中第i个位置之后插入一个数x，输出新的数组。

## 输入

三行，第一行输入n，第二行输入n个数，第三行依次输入i,x;

## 输出

一行，n+1个数，每个数之间用空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1083)

```
5
1 2 3 4 6
4 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1083)

```
1 2 3 4 5 6
```

## 提示

都是正整数，并且i的位置肯定是合法的(0=<i<=长度)
