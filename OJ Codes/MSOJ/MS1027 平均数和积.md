# 1027: 平均数和积

## 题目描述

输入三个整数，计算并输出它们的平均值（小数点保留两位）和乘积，写出程序。

## 输入

输入共一行，用空格个隔开的三个整数a，b，c

## 输出

输出共两行

第一行为三个数的平均数，平均数保留两位小数（四舍五入）

第二行为三个数的乘积

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1027)

```
12 45 89
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1027)

```
48.67
48060
```

## 提示

对于 30% 的数据：a,b,c<=1000;    
对于100%的数据：a,b,c<=100000。
