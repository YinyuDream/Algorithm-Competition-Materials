# 1319: 火柴棍

## 题目描述

众所周知的是，火柴棒可以拼成各种各样的数字。具体可以看下图：

通过2根火柴棒可以拼出数字“1”，通过5根火柴棒可以拼出数字“2”，以此类推。

现在LYK拥有k根火柴棒，它想将这k根火柴棒恰好用完，并且想知道能拼出的最小和最大的数分别是多少。

## 输入

一个数k表示火柴棍的数量(保证一定可以拼成数字)

## 输出

两个数，表示最小的数和最大的数。注意这两个数字不能带有前导0

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1319)

```
15
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1319)

```
108 7111111
```

## 提示

对于30%的数据，0<k<=20;

对于60%的数据，0<k<=50;

对于100%的数据，0<k<=200;
