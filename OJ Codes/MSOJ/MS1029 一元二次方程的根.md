# 1029: 一元二次方程的根

## 题目描述

求解一元二次方程ax2+bx+c=0的两个根

注：系数a,b,c从键盘输入，根的值保留两位小数

## 输入

输入一行，三个整数a,b,c，用空格隔开，题目意思如题

## 输出

输出一行，方程的两个根用空格隔开，如果无解输出”No Answer!”，

注：输出两个根依次从大到小

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1029)

```
3 6 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1029)

```
-0.42 -1.58
```

## 提示

对于100%的数据：a,b,c<=1000。

注：输出两个根依次从大到小
