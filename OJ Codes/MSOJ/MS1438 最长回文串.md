# 1438: 最长回文串

## 题目描述

对于一个字符串，如果他向前和向后读取都是相同的字符串，那么他就是回文字符串，比如madam，exe等等  
但是对于某些字符串，虽然它本身不是回文字符串，但是他的子串却是回文字符串，比如ababade，他的最长回文子串为ababa。  
现给定你n个字符串，求解他的最长回文子串的长度。

## 输入

第一行一个正整数n表示字符串的数量

后面n行，每行一个字符串

## 输出

n行，每行一个正整数表示最长回文子串的长度

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1438)

```
2
abcbabcbabcba
abacacbaaaab
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1438)

```
13
6
```

## 提示

对于30%的数据，n<=10,字符串长度<=1000;

对于100%的数据，n<=10,字符串长度<=100000
