# 1120: 分段函数计算

## 题目描述

问题提出：求解以下分段函数的值（x>0）。

当x=1或者x=2时，f(x)=x;

当x>2时，f(x)=f(x-1)+f(x-2)

输入x的值，求对应f(x)的值？

## 输入

输入一行，一个数x

## 输出

输出一行，输出对应f(x)的值

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1120)

```
3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1120)

```
3
```

## 提示

对于100的数据：x<=100;
