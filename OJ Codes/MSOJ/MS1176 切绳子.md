# 1176: ****切绳子

## 题目描述

有N条绳子，它们的长度分别为Li。如果从它们中切割出K条长度相同的

绳子，这K条绳子每条最长能有多长？答案保留到小数点后2位。(非四舍五入，直接舍去小数点两位后的数字)

## 输入

第一行两个整数N和K，接下来N行，描述了每条绳子的长度Li。

## 输出

切割后每条绳子的最大长度。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1176)

```
4 11
8.02
7.43
4.57
5.39
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1176)

```
2.00
```

对于100%的数据 0<Li<=100000.00 0<n<=10000 0<k<=10000
