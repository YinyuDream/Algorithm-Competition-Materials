# 1023: A*B问题

## 题目描述

输入两个正整数A和B，求A\*B。

## 输入

一行，包含两个正整数A和B，中间用单个空格隔开。1 <= A,B <= 500000。

## 输出

一个整数，即A\*B的值。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1023)

```
3 4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1023)

```
12
```

## 提示

对于100%的数据：a,b<=500000。
