# 1648: 小 R 与糖果

## 题目描述

小 R 喜欢吃糖果。

小 R 有 n 颗糖果，每颗糖果可以提供一个欢乐值。小 R 会一种神奇的魔法，每次施展魔法可以使他多得到一颗糖果，这颗糖果的欢乐值为 x+y，其中 x 和 y分别是小 R 已有的两颗糖果的欢乐值。小 R 在吃掉这些糖果之前想先施展 k 次魔法（必须施展 k 次）。现在小 R 想知道他最多能获得的欢乐值的和是多少。

## 输入

第一行有两个整数 n,k 表示初始糖果数量和施展魔法的次数，第二行包含 n个整数表示初始时小 R 的糖果。

## 输出

输出一个整数，表示欢乐值和的最大值。

答案对 10000007 取模。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1648)

```
2 2
3 6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1648)

```
33
```

## 提示

对于 60%的数据，有 n<=10^5， k<=10^5， |ai|<=10^5。  
对于 100%的数据，有 n<=10^5， k<=10^9， |ai|<=10^5。
