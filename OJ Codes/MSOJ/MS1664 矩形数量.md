# 1664: 矩形数量

## 题目描述

聪聪特别喜欢计算，特别是计算一个矩形中满足条件的子矩形的数量，明明出了很多道题来考查聪聪，结果都被聪聪轻轻松松的搞懂了。但是明明很不服气，觉得聪聪肯定是通过刷了大量类似的题来做“作弊”的，于是他放弃了常规的询问，从而提出了一个以前都没有出现过的询问。

现在有一个01的矩阵，矩阵内的数不是0就是1，如果直接去问聪聪有多少个矩形包含了k个1，那么聪聪肯定可以很容易想到答案，于是，明明更改了条件，把固定的k变成了一个区间[l,r]，即有多少个矩形包含的数字1的数量在区间[l,r]之间。

这还真难到了聪聪，他以前从没有遇到过类似的题，于是他不得不求助于你，希望你能帮他解决这个问题。

## 输入

第一行两个正整数n和m表示矩阵的大小

接下来n行，每行一个长度为m的01串，表示给定的矩阵

接下来一行两个正整数l,r，表示给定的区间

## 输出

一行，一个数表示符合条件的矩阵的数量

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1664)

```
2 3
100
011
2 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1664)

```
5
```

## 提示

5个矩形分别是:

(1,1)à(2,2) 矩形数量为2

(1,1)à(2,3) 矩形数量为3

(1,2)à(2,3) 矩形数量为2

(2,1)à(2,3) 矩形数量为2

(2,2)à(2,3) 矩形数量为2

|  |  |  |  |
| --- | --- | --- | --- |
| 编号 | n | m | 其他限制 |
| 1 | 20 | 20 | 无 |
| 2 | 30 | 200 |
| 3 | 30 |
| 4 | 1 | 50000 |
| 5 | 30 | 矩阵全0 |
| 6 | 30 | 矩阵全1 |
| 7 | 30 | l=0，r=n\*m |
| 8 | 30 | 无 |
