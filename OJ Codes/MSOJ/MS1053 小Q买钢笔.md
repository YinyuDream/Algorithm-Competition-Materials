# 1053: ***小Q买钢笔

## 题目描述

小Q决定用x元钱买钢笔，已知钢笔有三种，单价分别为4元，5元，6元，小Q想买尽可能多的钢笔，同时他又不想有剩余的钱，请你编写依程序制定出方案数(若存在买钢笔数相同且多个方案，则输出买钢笔4元最多的那个方案)

## 输入

输入仅一行，表示钱的总数，为正整数

## 输出

输出仅一行，分别是4元，5元，6元钢笔的数量，如果无法达到要求，则输出0 0 0.

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1053)

```
25
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1053)

```
5 1 0
```
