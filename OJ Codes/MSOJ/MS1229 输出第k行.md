# 1229: ***输出第k行

## 题目描述

已知杨辉三角形，输入一个正整数k，请输出杨辉三角形第k行的所有数据，每个数据之间用一个空格隔开。

## 输入

一个数。

## 输出

一行

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1229)

```
5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1229)

```
1 4 6 4 1
```

## 提示

k<=50
