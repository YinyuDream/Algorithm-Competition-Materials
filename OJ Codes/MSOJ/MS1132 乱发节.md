# 1132: ****乱发节

## 题目描述

农民约翰的某N(1 < N < 1000000)头奶牛正在过乱头发节！由于每头牛都意识到自己凌乱不堪 的发型，约翰希望统计出能够看到其他牛的头发的牛的数量.  
每一头牛i有一个高度所有N头牛面向东方排成一排，牛N在最前面，而 牛1在最后面.第i头牛可以看到她前面的那些牛的头，只要那些牛的高度严格小于她的高度，而且 中间没有比hi高或相等的奶牛阻隔.  
让N表示第i头牛可以看到发型的牛的数量；请输出Ci的总和(注意该头牛只可以看见它前面身高低于它的牛的头发)

## 输入

第一行n，第二行n个数表示牛的高度

## 输出

所有牛能看见的其他牛的头发的数量之和

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1132)

```
6
10 3 7 4 12 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1132)

```
5
```
