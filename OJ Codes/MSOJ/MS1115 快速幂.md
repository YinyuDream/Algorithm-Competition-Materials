# 1115: ****快速幂

## 题目描述

已知a和n,求a^n的值对123456取余后结果是多少，a<=1000000,n<=1000000

快速幂：

如果k是奇数:a^k=(a^(k/2))\*(a^(k/2))\*a

如果k是偶数:a^k=(a^(k/2))\*(a^(k/2))

## 输入

输入a和n的值

## 输出

输出结果

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1115)

```
2 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1115)

```
32
```
