# 1117: **最大公约数（递归）

## 题目描述

给定两个正整数m和n，求m和n的最大公约数。

## 输入

一行，两个数m和n

## 输出

一行，两个数的最大公约数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1117)

```
6 9
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1117)

```
3
```

## 提示

对于60%的数据，m,n<=10000000.

对于100%的数据，m,n<=10000000000
