# 1344: 最大矩形

## 题目描述

给你一个 N\*M 的 01 矩形，求一个面积最大的不包含数字 1 的矩形。

## 输入

第一行两个数 N， M。  
接下来 N 行，每行 M 个数为 0 或 1。

## 输出

一个数 ans 表示最大空矩形的面积。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1344)

```
2 4
1 0 0 0
0 1 1 0
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1344)

```
3
```

## 提示

对于 30%的数据,N<=200,M<=200  
对于 100%的数据,N<=1000,M<=1000
