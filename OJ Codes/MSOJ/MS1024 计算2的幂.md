# 1024: 计算2的幂

## 题目描述

给定非负整数n，求2n。

## 输入

一个整数n。0 <= n < 63。

## 输出

一个整数，即2的n次方。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1024)

```
3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1024)

```
8
```

## 提示

对于100的数据：n<63
