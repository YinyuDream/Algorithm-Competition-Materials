# 1094: ***成绩排序(升级版)

## 题目描述

n个同学参加考试，每个同学有一个成绩,并且每个同学有一个学号，按照成绩由高到低对每位同学排序。如果有多位同学的成绩相同则按照学号从小到大排列

## 输入

n+1行，第一行n，后面n行每行分别是学号和成绩，均为正整数

## 输出

n行，每行为学号和成绩，用空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1094)

```
5
1 89
4 90
3 90
2 78
5 60
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1094)

```
3 90
4 90
1 89
2 78
5 60
```

## 提示

n<=5000
