# 1033: ***四舍五入

## 题目描述

输入一个浮点数，求出四舍五入到整数后的结果。

## 输入

一个浮点数

## 输出

一个整数(一个无小数部分的数)

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1033)

```
1.478
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1033)

```
1
```

## 提示

这是一道数学题！

把一个浮点型直接转换成的整形的时候，无论小数部分是多少，都会直接舍去。
