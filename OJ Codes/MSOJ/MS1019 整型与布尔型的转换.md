# 1019: 整型与布尔型的转换

## 题目描述

将一个整型变量的值赋给一个布尔型变量，再将这个布尔型变量的值赋给一个整型变量，得到的值是多少？

## 输入

一个整型范围内的整数，即初始时整型变量的值。

## 输出

个整数，经过上述过程后得到的结果。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1019)

```
3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1019)

```
1
```
