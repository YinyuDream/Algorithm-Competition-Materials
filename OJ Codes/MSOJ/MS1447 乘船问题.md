# 1447: 乘船问题

## 题目描述

有n个人，第i个人重量为w[i]。每艘船的最大载重量均为C，且最多只能乘两个人。请问如何用最少的船装载所有人。

## 输入

第一行输入两个整数n和C，表示有n个人，每艘船最大载重量为C，第二行输入n个整数w[i]，表示每个人的质量，n<=1000000,w[i]<=1000000。

## 输出

输出一个整数，表示装载所有人用的最少船数。如果不可以装载所有人，输出“no way”

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1447)

```
3 100
50
90
40
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1447)

```
2
```

## 提示

n<=1000000,w[i]<=1000000
