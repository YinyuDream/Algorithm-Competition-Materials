# 1057: *偶数求和

## 题目描述

计算1--n（包括n）之间所有的偶数的和，其中n<=300

## 输入

一行，一个正整数n

## 输出

一行，一个结果表示偶数之和

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1057)

```
15
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1057)

```
56
```
