# 1081: *反向输出

## 题目描述

输入n个正整数，反向输出。n<=10000.

## 输入

两行，第一行一个正整数n，第二行n个正整数

## 输出

一行，n个正整数,每个数之间用空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1081)

```
5
1 2 3 4 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1081)

```
5 4 3 2 1
```

## 提示

n<=10000
