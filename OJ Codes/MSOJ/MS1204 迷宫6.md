# 1204: **迷宫6

## 题目描述

在一个n\*n的迷宫中，0表示可以走，1表示障碍物，已知起点和终点，每次只能向上下左右的方向移动一步。求从起点到终点的最短步数

## 输入

第一行n，后面一个n\*n的矩阵，最后一行起点和终点

## 输出

最短路径的距离

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1204)

```
3
0 0 0
0 0 1
1 0 0
1 1 3 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1204)

```
4
```

## 提示

n<=1000
