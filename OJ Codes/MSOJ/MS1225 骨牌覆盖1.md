# 1225: **骨牌覆盖1

## 题目描述

有一个2\*N的长方形方格，用1\*2的骨牌去铺满方格，请问有多少种铺法。因为最终的结果可能特别大，所以我们让结果对10000007取余。输出最终的结果

## 输入

一行，一个数N，表示长方形的长

## 输出

一行，表示方案数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1225)

```
5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1225)

```
8
```

## 提示

N<=10000
