# 1088: **插入一个数

## 题目描述

已知一个长度为n的有序不下降序列an , 现插入一个数x，要求插入x之后该序列仍然有序，输出插入后的序列。

## 输入

三行，第一行输入n，第二行n个数，第三行插入的数

## 输出

一行，新的数组，每个数字之间用空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1088)

```
5
1 2 3 5 6
4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1088)

```
1 2 3 4 5 6
```

## 提示

n<=100000;
