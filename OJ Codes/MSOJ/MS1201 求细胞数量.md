# 1201: ****求细胞数量

## 题目描述

一矩形阵列由数字0到9组成,数字1到9代表细胞,细胞的定义为沿细胞数字上下左右若还是细胞数字则为同一细胞,求给定矩形阵列的细胞个数。（1<=m,n<=100）

## 输入

整数m,n(m行，n列)

矩阵

## 输出

细胞的个数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1201)

```
4  10
0234500067
1034560500
2045600671
0000000089
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1201)

```
4
```
