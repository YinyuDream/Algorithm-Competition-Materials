# 1054: **出租车费用

## 题目描述

某市的的士起步价8元，可以行驶2.5公里，2.5公里之后，每公里按1.8元计算，不足1公里按1公里计算，输入里程数（公里），请问顾客需要付多少钱，结果保留一位小数。

## 输入

一行，里程数x，正数

## 输出

一行，需付的钱。结果保留一位小数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1054)

```
2.6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1054)

```
9.8
```
