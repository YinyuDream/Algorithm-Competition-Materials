# 1071: 排序1

## 题目描述

给你n个整数，请按从大到小的顺序输出其中前m大的数。

## 输入

第一行有两个数n,m

第二行包含n个各不相同，且都处于区间[-500000,500000]的整数。

## 输出

对测试数据按从大到小的顺序输出前m大的数。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1071)

```
5 2
-207693 190069 13569 -48891 -354975
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1071)

```
190069 13569
```

## 提示

对于100%的数据：n<=1000
