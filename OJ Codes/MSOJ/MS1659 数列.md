# 1659: 数列

## 题目描述

有一个长度为n的数列，数列中每个数都是[0，p-
1]之间的整数。

小A不知道数列中每个数的值，所以向小B做了m次询问。

每次小A会向小B询问一个区间[l, r]中所有数的和对p取模的结果。

问完所有问题后，小A发现小B的回答中似乎存在矛盾。

现在小A想找到最大的X，满足小B的前X次回答中不存在矛盾(X有可能等于m)。

## 输入

第一行三个整数n, m，p表示数列长度n，询问个数m和模数p。

之后m行，每行三个整数l，r，k，表示小B回答区间[l,r]中所有数的和 对p取模结果为k。

## 输出

输出最大的X，满足小B的前X次回答中不存在矛盾。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1659)

```
10 5 2 
1 2 0 
3 4 1 
5 6 0 
1 6 0 
7 10 1
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1659)

```
3
```

## 提示

对于 100%的数据，1 <=n,m<=106, 2<=p<=109 P不一定为质数，建议使用读入优化。
