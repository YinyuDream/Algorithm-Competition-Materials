# 1041: 平均绩点

## 题目描述

每门课的成绩分为A、B、C、D、F五个等级，为了计算平均绩点，规定A、B、C、D、F分别代表4分、3分、2分、1分、0分。

## 输入

有多组测试样例。

第一行一个整数N，表示测试数据组数，

以下N行，每行由一个或多个大写字母组成，字母之间由空格分隔。

## 输出

每组输出结果占一行。如果输入的大写字母都在集合｛A,B,C,D,F｝中，则输出对应的平均绩点，结果保留两位小数。否则，输出“Unknown”。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1041)

```
3
A B C D F
B F F C C A
D C E F
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1041)

```
2.00
1.83
Unknown
```

## 提示

对于100%的数据，N<=1000,每行字符个数不超过1000个
