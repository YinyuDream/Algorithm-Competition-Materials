# 1069: ****金币

## 题目描述

国王将金币作为工资，发放给忠诚的骑士。第一天，骑士收到一枚金币；之后两天（第二天和第三天）里，每天收到两枚金币；之后三天（第四、五、六天）里，每天收到三枚金币；这种工资发放模式会一直这样延续下去：当连续N天每天收到N枚金币后，骑士会在之后的连续N+1天里，每天收到N+1枚金币（N为任意正整数）。输入天数n，输出骑士一共获得的金币数。

## 输入

一行，天数n

## 输出

一行，金币数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1069)

```
6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1069)

```
14
```

## 提示

n<=10000
