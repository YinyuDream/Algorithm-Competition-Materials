# 1228: **杨辉三角形的输出

## 题目描述

输入一个数n，输出杨辉三角形的前n行。格式和杨辉三角线一样

## 输入

一个数n。

## 输出

杨辉三角形的前n行

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1228)

```
4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1228)

```
1
1 1
1 2 1
1 3 3 1
```

## 提示

n<=50
