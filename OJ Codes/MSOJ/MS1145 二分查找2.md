# 1145: *****二分查找2

## 题目描述

一个长度为n的有序不下降序列，给定m次查找，如果查找的数在序列中，输出在序列中第一次出现的位置，如果不在序列中，输出他在哪两个位置之间(保证查找的数肯定在序列两个端点之间）

## 输入

四行，第一行n，第二行n个数，第三行m，第四行m个数

## 输出

m行结果，每次结果用回车隔开，每行的结果用空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1145)

```
6
1 3 3 5 7 9
4 
1 4 9 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1145)

```
1
3 4
6
2
```

## 提示

n<=1000000,m<=10000;
