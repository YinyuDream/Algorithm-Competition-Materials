# 1160: **小A点菜

## 题目描述

小A拿到NOIP奖金之后准备请朋友小B吃饭，由于小A平时是个铁公鸡，所以小B想狠狠的宰他一顿。于是小B奉行“不把钱吃光不罢休”的原则。问小B要点菜花光小A的所有奖金，有多少种点菜方案。由于是一个小餐馆，所以每一种菜最多可以点一份。

## 输入

第一行两个数字，n和m，分别表示菜的种类和小A的奖金，n<=100.m<=10000

第二行n个数，分别表示每种菜的价钱。

## 输出

一个正整数，表示点菜方案数，保证答案的范围在int之内。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1160)

```
4 4 
1 1 2 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1160)

```
3
```
