# 1050: *最大数输出

## 题目描述

输入三个整数,输出最大的数。

## 输入

输入为一行，包含三个整数，数与数之间以一个空格分开。

## 输出

输出一行，包含一个整数，即最大的整数。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1050)

```
10 20 56
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1050)

```
56
```
