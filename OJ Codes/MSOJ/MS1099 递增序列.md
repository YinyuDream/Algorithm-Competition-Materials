# 1099: **递增序列

## 题目描述

已知一个不下降序列，请问要如何删数才能让他变成一个严格上升序列(a[i]<a[i+1])。请输出最终的严格上升序列

## 输入

两行，第一行n，第二行n个数

## 输出

一个严格上升序列

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1099)

```
6
1 2 2 4 4 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1099)

```
1 2 4 5
```

## 提示

n<=100000
