# 1240: ****数字三角形3

## 题目描述

数字三角形必须经过某一个点(n/2,n/2)，使之走的路程和最大

## 输入

第1行n，表示n行

第2到n+1行为每个的权值

程序必须经过n/2,n/2这个点

## 输出

最大值

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1240)

```
5
70 
61 2 
67 34 67 
34 93 24 32 
3 0 76 36 4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1240)

```
275
```

## 提示

n<=100,每个数<=1000
