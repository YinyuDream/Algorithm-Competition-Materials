# 1095: **查找

## 题目描述

给定一个长度为n的不下降序列，再给定一个数字x，判断x是否在序列中，如果在，输出在序列中的位置，如果不在，输出在序列的哪两个位置之间（保证x在序列首位之间）.

## 输入

第一行n，第二行n个数，第三行x

## 输出

如果在序列中则输出位置，如果不在则输出在哪两个位置之间，用空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1095)

```
5
1 3 5 7 9
6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1095)

```
3 4
```

## 提示

n<=1000000.
