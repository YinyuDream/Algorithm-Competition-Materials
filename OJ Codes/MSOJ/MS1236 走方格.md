# 1236: **走方格

## 题目描述

已知一个n\*n的方格，小明在方格的左上角（1,1）,要走到方格的右下角（n,n），请问有多少种走法，已知小明只可以向右和向下移动。由于走法可能特别多，所以结果对123456取余

## 输入

一行，n

## 输出

方案数。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1236)

```
3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1236)

```
6
```
