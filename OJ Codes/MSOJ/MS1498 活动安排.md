# 1498: 活动安排

## 题目描述

有n个活动需要使用教室，每个活动都有对应的起止时间[si,fi],问如何安排才能举办更多的活动，最多能举办的活动有多少？

## 输入

第一行一个整数n；  
接下来的n行，每行两个整数si和fi。

## 输出

输出互相兼容的最大活动个数。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1498)

```
4
1 3
4 6
2 5
1 7
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1498)

```
2
```

## 提示

n<=1000;
