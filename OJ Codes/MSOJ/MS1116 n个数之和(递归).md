# 1116: **n个数之和(递归)

## 题目描述

输入n，再输入n个数，求n个数之和，请用递归求解,n<=10000.每个数<=1000

## 输入

第一行n，第二行n个数

## 输出

一个结果

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1116)

```
4
1 2 3 4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1116)

```
10
```
