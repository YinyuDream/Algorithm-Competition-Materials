# 1058: **奇数求和

## 题目描述

计算非负整数 m 到 n（包括m 和 n ）之间的所有奇数的和，其中，m 不大于 n，且n 不大于300。例如 m=3, n=12, 其和则为：3+5+7+9+11=35。

## 输入

一行，两个数m和n。m，n为正整数

## 输出

一行，一个结果，表示m到n之间所有奇数之和

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1058)

```
7 15
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1058)

```
55
```
