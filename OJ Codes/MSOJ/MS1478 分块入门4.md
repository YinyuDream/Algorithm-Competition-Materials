# 1478: 分块入门4

## 题目描述

给出一个长为n的数列，以及n个操作，操作涉及区间加法，区间求和。

## 输入

第一行输入一个数字n。  
第二行输入n个数字，第i个数字为ai，以空格隔开。  
接下来输入n行询问，每行输入四个数字opt、l、r、c，以空格隔开。  
若opt=0，表示将位于[l,r]的之间的数字都加c。  
若opt=1，表示询问位于[l,r]的所有数字的和mod(c+1)。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1478)

```
4
1 2 2 3
0 1 3 1
1 1 4 4
0 1 2 2
1 1 2 4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1478)

```
1
4
```
