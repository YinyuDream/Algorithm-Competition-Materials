# 1522: 数列操作(一)

## 题目描述

先给定一个长度为n数列，再给定m个操作，现在需要维护五个操作：

1
x：在光标的前面插入一个数字x。

2：删除光标前的最后一个数字，如果光标前没有数字则忽略。

3：左移一格光标，如果光标已经在最左边则忽略。

4：右移一格光标，如果光标已经在最右边则忽略。

5
k：求前k个数的前缀和，保证k<=数列长度。

初始时光标在数列的最后一个数后面

数据范围：n,m,k<=100000,x<=int

## 输入

参照问题描述

## 输出

对于每个询问，输出一个答案，每个答案占一行

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1522)

```
2
3 2
5
3
1 6
4
2
5 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1522)

```
9
```

## 提示

n,m,k<=100000,x<=int
