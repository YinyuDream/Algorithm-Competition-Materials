# 1184: ****最长不下降子序列

## 题目描述

已知一个长度n的无序数列，求序列中的最长不下降子序列的长度

## 输入

第一行n，第二行n个数

## 输出

最长不下降子序列的长度

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1184)

```
7
1 3 6 8 4 5 7
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1184)

```
5
```

## 提示

n<=100000;
