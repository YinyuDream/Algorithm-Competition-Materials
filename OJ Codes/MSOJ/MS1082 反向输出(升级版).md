# 1082: **反向输出(升级版)

## 题目描述

输入一堆数，当输入0的时候表示输入结束，反向输出(不包括0)。n<=10000.

## 输入

一行，一堆数，输入第一个0表示结束

## 输出

一行，每个数之间用空格隔开

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1082)

```
1 2 3 4 5 0
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1082)

```
5 4 3 2 1
```

## 提示

n<=10000
