# 1107: **矩阵变换

## 题目描述

输入一个n\*n的矩阵，交换矩阵的行和列，变成一个新的矩阵。

## 输入

第一行n，后面一个n\*n矩阵

## 输出

```
n*n矩阵
```

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1107)

```
3
1 2 3
3 4 7
5 6 8
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1107)

```
1 3 5
2 4 6
3 7 8
```

## 提示

n,m<=100
