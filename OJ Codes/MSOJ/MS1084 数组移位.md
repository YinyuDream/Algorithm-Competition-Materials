# 1084: **数组移位

## 题目描述

输入一个整数组，当输入0的时候表示数组输入结束(0不算在数组内),把数组的最后一个元素移动到开头，然后把数组的剩下元素都向后移动一位，输出新的数组。

## 输入

一行，很多书，当输入第一个0的时候表示结束

## 输出

一行，一个新的数组

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1084)

```
1 2 3 4 5 0
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1084)

```
5 1 2 3 4
```

## 提示

n<=10000
