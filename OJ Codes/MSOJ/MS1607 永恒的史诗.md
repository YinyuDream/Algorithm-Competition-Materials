# 1607: 永恒的史诗

## 题目描述

真是不幸，银月城中竟出现了达尔坎这样可耻的叛徒，他将掌控着屏障的三月之匙献给了阿尔萨斯。

现在银月城中共有n个军团集结点，由m条单向道路相连接，经过每条路需要花费一定的时间。现在阿尔萨斯在银月城门口的1号集结点,**只要天灾大军能攻占位于n号集结点的银月城大厅,银月城便会就此沦陷**，阿尔萨斯决定派出几只食尸鬼军团完成这项任务。唯一的阻碍是，银月城中的一些集结点有强大的魔法屏障保护，**不破坏所有保护该集结点的屏障便无法进入集结点**。而每个受保护的集结点的屏障是由在其它集结点中的魔法屏障发生器所提供的，只有三月之匙能够关闭屏障。

现在，所有石像鬼军团从1号集结点出发，每个石像鬼军团拥有一把由霜之哀伤的力量复制出来的三月之匙。一旦进入某个集结点，三月之匙就会马上关闭护盾发生器，但复制的三月之匙也会失去控制屏障的力量 **（意味着这只军团失去了打开屏障的能力）。**

因为阿尔萨斯急着去虐待炉石玩家，所以他把这个任务交给了你。阿尔萨斯是一个经济实惠的人（?），他希望到达银月城大厅的时间最短，请你帮他计算一下这个值是多少。

## 输入

第一行输入两个数n,m。

接下来m行，每行输入三个数u,v,t表示从u号集结点到v号集结点有一条边,需要时间t。

接下来n行，每行描述一个集结点的受保护情况。

每行的第一个数Li，表示第i个集结点受到Li个屏障的保护，之后的Li个数为这些屏障所在集结点编号。若Li=0 ，说明该集结点不受保护。

输入数据保证 L1=0。

## 输出

一行仅包含一个整数，输出最少花费的时间。

5 5

0

```

```

## 提示

派出一只食尸鬼军团，路线为1→2→5，总共花费时间8。

派出两只食尸鬼军团，路线为1→2,1→3→5，总共花费时间5。

对于100%的数据，满足N≤3000,M≤70000,1≤T≤108。
