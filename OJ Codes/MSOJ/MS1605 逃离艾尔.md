# 1605: 逃离艾尔

## 题目描述

艾尔共有n个地区，编号从1到n，每个地区居住着一些星灵，并且有一个传送门和一个星门。

当两个地区为友好地区时，其中的星灵可以通过传送门相互转移，传送门不限制使用人数。(特殊地，对于地区a,b,c，如果a与b互为友好地区，b与c互为友好地区，则a与c互为友好地区)

每个城市的星门能通向一个或多个特定的地区，且一个星门只能通向特定地区一次，并限制使用人数。所有的星灵都必须逃往首都1号地区才能乘虚空辉光舰离开。

**1****号地区具有以下特点：**

1.不与任何地区互为友好地区

2.没有星门

3.没有星灵居住

现在给出1到n号城市的星灵个数pi；m对ai,bi表示ai,bi互为友好地区；k对ci,di,ei表示ci地区星门通向di号地区，最多通过ei个星灵。

你需要求出最多有多少星灵能够逃离艾尔。

## 输入

第一行三个整数n,m,k，分别表示地区数、友好关系数、星门关系数。

第二行n个整数，pi表示第i号地区的星灵数。

接下来m行，每行两个整数ai,bi，表示ai,bi互为友好地区。

接下来k行，每行三个整数ci,di,ei，表示ci号地区星门通往di号地区，限制ei个星灵通过。

## 输出

一行，一个整数，表示能够逃离艾尔的最大星灵数。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1605)

```
4 1 2
0 2 4 5
2 4
2 1 4
3 1 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1605)

```
8
```

## 提示

对于20%：1≤n,m,k≤10。

对另10%：1≤n,m,k≤1000，且i与i+1号互为友好地区(
