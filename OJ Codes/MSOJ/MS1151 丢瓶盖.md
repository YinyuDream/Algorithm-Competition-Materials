# 1151: ***丢瓶盖

## 题目描述

陶陶是个贪玩的孩子，他在地上丢了A个瓶盖，为了简化问题，我们可以当作这A个瓶盖丢在一条直线上，现在他想从这些瓶盖里找出B个，使得距离最近的2个距离最大，他想知道，最大可以到多少呢？

## 输入

第一行，两个整数，A,B。（B<=A<=100000）

第二行，A个整数，分别为这A个瓶盖坐标。<=1e9

## 输出

仅一个整数，为所求答案。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1151)

```
5 3
1 2 3 4 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1151)

```
2
```
