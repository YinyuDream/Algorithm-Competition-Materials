# 1060: **最大最小值

## 题目描述

输入n个整数，求这n个数之中最大值和最小值分别是多少

## 输入

两行，第一行输入n，第二行输入n个数

## 输出

两行，第一行是最大值，第二行是最小值

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1060)

```
5
85 78 90 99 60
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1060)

```
99
60
```

## 提示

n<=10000,每个数的绝对值小于10000000000
