# 1195: *迷宫2

## 题目描述

给定一个N\*N方格的迷宫，迷宫由0和1组成，0表示可以走，1表示不可以走。再给定起点和终点的位置。问。从起点到终点的最短距离，如果不可以到达，输出-1.

## 输入

第一行n表示迷宫的大小，后面一个由0和1组成的n\*n的矩阵。

## 输出

最短路径，如果不可以到达，则输出-1

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1195)

```
3
0 0 0
1 0 0
0 0 0
1 1 3 2
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1195)

```
3
```

## 提示

n<=100;
