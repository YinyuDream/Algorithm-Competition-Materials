# 1063: ***韩信点兵

## 题目描述

韩信点兵时让士兵分别以三人一排、五人一排、七人一排的变换队形，每次只看最后一排有多少人就知道总人数了(余数)。输入三人、五人、七人一排的尾排数量，求出军队人数（或者无解），如果无解则输出“No”。总人数不小于10，不大于100.

## 输入

一行，三个数，分别表示三人一排，五人一排，七人一排的尾排多出来的人数。

## 输出

一行，一个数，表示军队人数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1063)

```
2 1 6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1063)

```
41
```
