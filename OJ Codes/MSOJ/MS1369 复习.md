# 1369: 复习

## 题目描述

一给你一个序列 A， 维护两种操作：  
1 l r:询问对于 A 的子区间 A[l„r]， 满足“比之前所有数都大” 的数  
有多少个？ (第一个数默认算一个)  
2 x y:将 A[x]的值修改为 y。

## 输入

第一行两个数 N,M， 分别表示数列长度以及操作个数；  
第二行有 N 个数， 表示这个序列；  
接下来 M 行每行表示两种操作， 分别为  
1 l r:表示一个询问操作  
2 x y:表示一个修改操作

## 输出

对于每一个询问操作， 输出一个数表示答案

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1369)

```
5 3
1 2 3 4 5
1 1 5
2 1 5
1 1 5
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1369)

```
5
1
```

## 提示

对于 20%的数据， N,M<=100;  
对于 40%的数据， N,M<=10000;  
对于额外 20%的数据， 只有一个询问操作；  
对于额外 20%的数据， 没有修改操作；  
对于 100%的数据， N,M<=2\*10^5。
