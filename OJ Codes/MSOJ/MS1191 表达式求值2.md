# 1191: ***表达式求值2

## 题目描述

给定一个包含‘+’，‘-’，‘\*’，'/'的算术表达式，并且数字都是个位整数，并且没有负数，请你编程计算表达式的值。注意‘/’是整除。比如4\*3/5结果应该是2

## 输入

一行表达式

## 输出

表达式的结果

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1191)

```
1+2*3/4-6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1191)

```
-4
```

## 提示

表达式长度<=1000
