# 1660: 炸弹

## 题目描述

有n个炸弹分布在一条数轴上。

现在需要玩家以一定的能量引爆某一个炸弹，而炸弹爆炸会引起连锁
反应导致更多的炸弹爆炸。

炸弹爆炸时会携带能量X，可以引爆和他距离<=X的所有炸弹。

当一个炸弹被能量叉的爆炸引爆时，该炸弹会携带2X/3 (向下取整)的能量。

玩家可以设置第一个引爆的炸弹的能量，现在请问，如果想引爆所有炸弹，第一个引爆的炸弹的能量最少是多少呢？

## 输入

第一行一个数n，表示炸弹的数量。  
之后一行n个非负整数，表示每个炸弹的坐标。

## 输出

输出炸弹的能量最少是多少。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1660)

```
5
80 100 30 110 10
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1660)

```
50
```

## 提示

对于100%的数据，2<=n<=106 保证炸弹坐标在[0, 500000000]范围内。
