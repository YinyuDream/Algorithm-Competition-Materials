# 1440: 三元上升子序列

## 题目描述

Erwin最近对一种叫"thair"的东西巨感兴趣。。。在含有n个整数的序列a1,a2......an中，三个数被称作"thair"当且仅当i<j<k且ai<aj<ak

求一个序列中"thair"的个数。

## 输入

第一行输入n，第二行输出n个数

## 输出

“thair”的个数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1440)

```
4
2 1 3 4
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1440)

```
2
```

## 提示

对于30%的数据，n<=100

对于60%的数据，n<=3000

对于100%的数据，n<=30000
