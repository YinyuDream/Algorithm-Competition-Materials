# 1189: *****噪音

## 题目描述

给出n头牛(n<=100000)，每头牛都会发出一个噪声，大小为v[i]。然而这个叫声只会被离他最近的一个比他高的牛听到，当然这个叫声是双向传播的(自己不会听到自己的噪音)，问牛收到的最大的噪音是多少(即该头牛收到的所有噪音之和最大是多少)

## 输入

第一行n，后面n行，每行两个整数数，第一个数表示高度h，第二个数表示噪音的大小v。

## 输出

牛收到的最大噪音

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1189)

```
3
4 2
3 5
6 10
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1189)

```
7
```
