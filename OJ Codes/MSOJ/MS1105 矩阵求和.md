# 1105: *矩阵求和

## 题目描述

输入一个n\*m整形矩阵，求出整个矩阵里面的元素相加之和。

## 输入

第一行，n和m，后面n行每行m个数

## 输出

矩阵之和

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1105)

```
2 3
1 2 3
4 5 6
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1105)

```
21
```

## 提示

n,m<=1000，每个数<=100000
