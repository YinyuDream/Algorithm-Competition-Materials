# 1273: 受欢迎的牛

## 题目描述

每头牛都有一个梦想：成为一个群体中最受欢迎的名牛！在一个有 N(1<=N<=10,000)头牛的牛群中，给你 M(1<=M<=50,000)个二元组(A,B),表示 A 认为 B 是受欢迎的。既然受欢迎是可传递的，那么如果A 认为 B 受欢迎， B 又认为 C 受欢迎,则 A 也会认为 C 是受欢迎的，哪怕 A 没有明确地向其他牛表示过这一点。你的任务是计算被所有其它的牛都喜欢的牛的头数。

## 输入

第一行，两个数， N 和 M。  
第 2～M+1 行，每行两个数， A 和 B，表示 A 认为 B 是受欢迎的。

## 输出

一个数，被其他所有奶牛认为受欢迎的奶牛头数。

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1273)

```
3 3
1 2
2 1
2 3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1273)

```
1
```

## 提示

3 号奶牛是唯一被所有其他奶牛认为是受欢迎的。

对于 40%的数据， N<=100,M<=100。  
对于 60%的数据， N<=2000,M<=10000;  
对于 100%的数据，有 N <=10000， M<=50000。
