# 1080: **最大质因数

## 题目描述

任何一个合数都可以写成多个质数相乘，给定一个数n，求出这个数的最大质因数是多少。

## 输入

一行，一个数n

## 输出

一个数，最大质因数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1080)

```
15
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1080)

```
5
```

## 提示

对于60%的数据，n<=1000000;

对于100%的数据，n<=10000000000;
