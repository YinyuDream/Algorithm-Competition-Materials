# 1096: 素数求和

## 题目描述

求解1---N以内所有素数之和。

## 输入

输入一行，一个数N

## 输出

输出一行，1---N的和

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1096)

```
10
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1096)

```
17
```

## 提示

对于100%的数据：n<=100000;
