# 1226: ***骨牌覆盖2

## 题目描述

有一个2\*N的长方形方格，有1\*2和2\*2的骨牌去铺满方格，请问有多少种铺法。

## 输入

一行，N

## 输出

一个结果，方案数

## 样例输入 [Copy](http://10.202.120.248/problem.php?id=1226)

```
3
```

## 样例输出 [Copy](http://10.202.120.248/problem.php?id=1226)

```
5
```

## 提示

n<=20
