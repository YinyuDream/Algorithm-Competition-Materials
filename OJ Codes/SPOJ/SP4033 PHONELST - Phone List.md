# SP4033 PHONELST - Phone List

## 题目描述

给定 $n$ 个长度不超过 $10$ 的数字串，问其中是否存在两个数字串 $S,T$，使得 $S$ 是 $T$ 的前缀。有多组数据，数据组数不超过 $40$。

## 输入格式

第一行，一个整数 $T$，表示数据组数。
对于每组数据，第一行一个数 $n$，接下去 $n$ 行，输入 $n$ 个数字串。

## 输出格式

对于每组数据，若存在两个数字串 $S,T$，使得 $S$ 是 $T$ 的前缀，则输出 $\texttt{NO}$，否则输出 $\texttt{YES}$。

## 输入输出样例 #1

### 输入 #1

```
2
3
911
97625999
91125426
5
113
12340
123440
12345
98346
```

### 输出 #1

```
NO
YES
```

## 说明/提示

### 数据范围

$n \le 1 \times 10^4$。
