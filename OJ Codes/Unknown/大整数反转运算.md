# 大整数反转运算

## 题目描述

给定两个非负整数$A$和$B$（以字符串形式输入，长度不超过500），首先将每个数字反转（即数字顺序颠倒，例如123反转为321），然后计算反转后的两个数的和、差、积。输入保证$A$反转后的值大于等于$B$反转后的值，因此差为非负。输出三个结果，每个结果为一个非负整数，分别表示和、差、积。

## 输入

两行，每行一个非负整数字符串，表示$A$和$B$。

## 输出

三行，第一行为反转后的和，第二行为反转后的差，第三行为反转后的积。

## 样例输入

```
456
123
```

## 样例输出

```
975
333
209934
```
