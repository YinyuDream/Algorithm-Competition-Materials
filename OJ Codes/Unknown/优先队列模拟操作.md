# 优先队列模拟操作

## 题目描述

实现一个最小优先队列的交互式操作程序。程序支持以下操作：1. 插入一个整数；2. 查询队列中的最小元素并输出；3. 删除队列中的最小元素；4. 输出队列的大小；5. 检查队列是否为空并输出'ture'或'false'；7. 退出程序。输入以操作7结束。

## 输入

输入包含多行，每行第一个整数表示操作类型。如果是操作1，则后面跟一个整数表示要插入的值。输入以操作7或文件结束终止。

## 输出

对于操作2，输出一行，格式为'队列顶部元素是: X'，其中X是最小元素值。对于操作4，输出一行，格式为'队列大小是: S'，其中S是队列大小。对于操作5，如果队列为空输出'ture'，否则输出'false'。其他操作不产生输出。

## 样例输入

```
1 5
1 3
2
3
3
5
7
```

## 样例输出

```
队列顶部元素是: 3
ture
```
