# 网格路径问题

## 题目描述

在一个 $n$ 行 $m$ 列的网格中，每个格子可能是空地（用0表示）或障碍（用1表示）。你需要计算从左上角（第1行第1列）到右下角（第 $n$ 行第 $m$ 列）的路径数量，每次移动只能向右或向下，且不能经过障碍格子。起点和终点保证是空地。结果需要对123456取模。

## 输入

第一行包含两个整数 $n$ 和 $m$（$1 \leq n, m \leq 1000$），表示网格的行数和列数。接下来 $n$ 行，每行包含 $m$ 个整数（0或1），表示网格的状态，0表示空地，1表示障碍。

## 输出

输出一个整数，表示从起点到终点的路径数量模123456的结果。

## 样例输入

```
3 3
0 0 0
0 1 0
0 0 0
```

## 样例输出

```
2
```
