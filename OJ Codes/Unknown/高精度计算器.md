# 高精度计算器

## 题目描述

实现一个高精度计算器，能够计算两个大整数的和、差、积、商。整数可能为负数，输入以字符串形式给出，支持加（+）、减（-）、乘（*）、除（/）四种运算。对于除法，使用整数除法，如果除数为0则输出'Null'。输出计算结果，包括符号。

## 输入

第一行输入第一个整数（字符串，可能以'-'开头表示负数）。
第二行输入一个运算符字符（+、-、*、/）。
第三行输入第二个整数（字符串，可能带负号）或当运算符为'/'时输入一个整数（表示除数）。

## 输出

输出计算结果。如果结果为负，输出负号后跟数字；如果结果为0，输出0；对于除法，如果除数为0，输出'Null'。结果不输出前导零（除非结果为0）。

## 样例输入

```
123
+
456
```

## 样例输出

```
579
```
