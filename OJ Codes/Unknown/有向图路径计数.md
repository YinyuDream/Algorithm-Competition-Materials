# 有向图路径计数

## 题目描述

给定一个有向图，节点数为$n$，边数为$m$，求从节点$1$到节点$n$的长度恰好为$t$的路径数量。路径长度定义为经过的边数，允许重复节点和边。结果需要对$45989$取模。

## 输入

输入包含多行：第一行包含五个整数$n$, $m$, $t$, $a$, $b$，其中$n$为节点数，$m$为边数，$t$为目标路径长度，$a$和$b$在本题中未使用。接下来$m$行，每行包含两个整数$u$和$v$，表示一条从$u$到$v$的有向边。节点编号从$0$到$n-1$，但路径计算时节点从$1$开始计数。

## 输出

输出一个整数，表示从节点$1$到节点$n$的长度为$t$的路径数量对$45989$取模的结果。

## 样例输入

```
3 2 2 1 3
0 1
1 2
```

## 样例输出

```
1
```
