# 数字频率统计

## 题目描述

给定 $n$ 个正整数，统计每个数字出现的次数。从最大的数字开始向下，输出前两个出现过的数字的出现次数（如果存在），每个次数后跟一个空格，然后输出总共出现的不同数字的个数。

## 输入

第一行一个整数 $n$，表示数字的个数（$0 \leq n \leq 10000$）。接下来 $n$ 行，每行一个正整数，范围在1到10000之间。

## 输出

输出前两个出现过的最大数字的出现次数，每个次数后跟一个空格（如果少于两个，则只输出存在的那些），然后输出一个整数，表示总共出现的不同数字的个数。

## 样例输入

```
5
3
5
3
2
5
```

## 样例输出

```
2 2 3
```
