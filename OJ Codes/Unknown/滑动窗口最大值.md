# 滑动窗口最大值

## 题目描述

给定一个长度为 $n$ 的数组和一个整数 $k$，对于每个 $i$ 从 $1$ 到 $n$，输出子数组 $a[\max(1, i-k+1) \dots i]$ 中的最大值。

## 输入

第一行包含两个整数 $n$ 和 $k$ ($1 \leq n \leq 10^6$, $1 \leq k \leq n$)。第二行包含 $n$ 个整数，表示数组 $a[1..n]$，元素值在整数范围内。

## 输出

输出一行 $n$ 个整数，第 $i$ 个整数表示位置 $i$ 的滑动窗口最大值，整数之间用一个空格分隔。

## 样例输入

```
5 3
1 3 -1 -3 5
```

## 样例输出

```
1 3 3 3 5
```
