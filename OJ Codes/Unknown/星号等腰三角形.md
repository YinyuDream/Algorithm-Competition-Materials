# 星号等腰三角形

## 题目描述

给定一个正整数 $N$，打印一个高度为 $N$ 的等腰三角形。三角形由星号 '*' 组成，底部宽度为 $2*N-1$。每行先打印适当数量的空格使三角形居中，然后打印星号。

## 输入

输入包含一个整数 $N$ ($1 \leq N \leq 100$)，表示三角形的高度。

## 输出

输出 $N$ 行，每行包含空格和星号，形成一个等腰三角形。具体规则：对于第 $i$ 行（从 1 开始），先打印 $N - i$ 个空格，然后打印 $2*i - 1$ 个星号。

## 样例输入

```
5
```

## 样例输出

```
    *
   ***
  *****
 *******
*********
```
