# 环状数组四元素和最值

## 题目描述

给定一个长度为 $n$ 的环状数组 $a$（索引从1开始），计算所有连续4个元素的和（考虑环状特性），并找出这些和中的最大值与最小值对应的起始索引。如果有多个最大或最小值，输出最早出现的索引。

## 输入

第一行输入一个整数 $n$（$1 \leq n \leq 100000$），第二行输入 $n$ 个整数，表示数组 $a$ 的元素（$-1000000 \leq a_i \leq 1000000$）。

## 输出

输出两个整数，以空格分隔，分别表示最大和的起始索引和最小和的起始索引。

## 样例输入

```
5
1 2 3 4 5
```

## 样例输出

```
2 1
```
