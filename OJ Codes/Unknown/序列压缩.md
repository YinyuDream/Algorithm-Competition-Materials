# 序列压缩

## 题目描述

给定一个长度为 $n$ 的整数序列，定义压缩操作如下：从左到右扫描序列，当遇到相邻两个元素相等时，从当前位置开始向右找到最长的连续非递增子序列（即对于该段中的每个位置，都有 $a[i] \geq a[i+1]$），然后删除这段序列的前几个元素，只保留最后一个元素。删除后序列长度减少，扫描继续，直到扫描完整个序列。输出最终序列的前 $m$ 个元素，其中 $m$ 为原始序列长度减去总共删除的元素个数。

## 输入

第一行一个整数 $n$（$1 \leq n \leq 100000$）。第二行 $n$ 个整数，表示序列 $a[1], a[2], \ldots, a[n]$。保证序列中每个整数的绝对值不超过 $10^9$。

## 输出

一行，输出最终序列的前 $m$ 个元素，元素之间用一个空格隔开，末尾无空格。

## 样例输入

```
5
2 2 3 3 1
```

## 样例输出

```
2 1
```
