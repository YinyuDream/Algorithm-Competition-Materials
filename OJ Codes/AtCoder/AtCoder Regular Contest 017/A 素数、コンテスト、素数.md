# AT_arc017_1 [ARC017A] 素数、コンテスト、素数

## 题目描述

我非常喜欢算法和竞赛，每次都不落下地参加 AtCoder Regular Contest（ARC）。  
然而有一次，在大学里被一群可疑的人突然搭话：“你相信素数之光吗？”从那以后我的状态就有些奇怪了。  
虽然我的数学水平一般，但素数还是知道的。素数是只能被 $1$ 和它本身整除的正整数。  
当然，我也知道 $1$ 不是素数。不过“素数之光”到底是什么，我也搞不太明白。  
自从听了那群人的话之后，我就变得有点不对劲。脑海里总有素数的影子，每次看到素数都会莫名其妙地高兴起来。  
以往每次都参加的 ARC，现在如果不是素数编号的那一场，总觉得不顺利，干脆就不参加了。  
说起来，现在正好又有一场 ARC 开始了。这次的 ARC，我能顺利参加吗？

输入将以如下格式从标准输入中给出。

> $N$

- $N\ (17 \leq N \leq 1,000,000)$ 表示 ARC 是第 $N$ 次举办。

如果可以参加 ARC$N$，也就是 $N$ 是素数时，输出一行 `YES`，否则输出一行 `NO`。

例如：

```
17
```

```
YES
```

这次的 ARC017，因为 $17$ 是素数（不能被 $2$ 到 $16$ 之间的任何整数整除），所以可以参加。

```
18
```

```
NO
```

下次的 ARC018，因为 $18$ 可以被 $2$ 或 $3$ 整除，所以不能参加。

```
999983
```

```
YES
```

ARC999983 不知道什么时候会举办呢。

```
672263
```

```
NO
```

$672263$ 除了 $1$ 和它本身，还能被 $547$ 和 $1229$ 整除。

## 输入格式

输入包含一行，一个整数 $N$。

## 输出格式

如果 $N$ 是素数，输出一行 `YES`；否则输出一行 `NO`。

## 说明/提示

- $N$ 的取值范围为 $17 \leq N \leq 1,000,000$。
- $1$ 不是素数。
