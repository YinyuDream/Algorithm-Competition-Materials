# U366057 帕蒂沙兰

## 题目背景

帕蒂沙兰，一种在须弥雨林中绽放的圣洁而高贵的花卉。为了重要的庆典，牛露需要你采集这些美丽的花朵，编织一个最盛大的花环。

## 题目描述

在你的面前，有 $n$ 朵帕蒂沙兰排成一排，从左到右依次编号为 $1, 2, \dots, n$。第 $i$ 朵花的颜色编号为 $a_i$。你的目标是从中挑选出尽可能多的花，用于编织花环。

在采集和编织的过程中，你需要遵守以下两条规则：

1.  **体力限制**：你的体力有限。在你采集了一朵花之后，必须直接跳过它身后的 $k$ 朵花，才能采集下一朵。换句话说，如果你采集了位于第 $i$ 朵花，那么你下一朵能采集的花的位置 $j$ 必须满足 $j \ge i + k + 1$。

2.  **美学要求**：编织成的花环必须和谐美观。对于你选出的所有花朵，最高颜色编号与最低颜色编号的差必须**严格小于** $m$。设你采集了 $x$ 朵花，其颜色分别为 $b_1, b_2, \dots, b_x$，则必须满足：
    $$\max\limits_{i=1}^{x}\{b_i\} - \min\limits_{i=1}^{x}\{b_i\} < m$$

请问，你最多能采集多少朵满足上述所有条件的帕蒂沙兰？

## 输入格式

第一行包含三个整数 $n, m, k$，分别表示帕蒂沙兰的总数量、颜色编号差的上限以及采集时需要跳过的花朵数量。

第二行包含 $n$ 个正整数 $a_1, a_2, \dots, a_n$，表示每一朵帕蒂沙兰的颜色编号。

## 输出格式

输出一个整数，代表满足条件的花环所能包含的帕蒂沙兰的最大数量。

## 输入输出样例 #1

### 输入 #1

```
6 3 1
1 2 3 1 2 3
```

### 输出 #1

```
3
```

## 输入输出样例 #2

### 输入 #2

```
6 2 1
1 1 4 5 1 4
```

### 输出 #2

```
2
```

## 说明/提示

#### 样例1说明:

满足体力限制下，牛露可以采集位于 $\{1,3,5\}$ 的帕蒂沙兰编织成花环，

#### 数据范围:

对于 $10 \%$ 的数据，$1 \le n \le 20，k=0，m=1$。

对于 $20 \%$ 的数据，$1 \le n \le 20，0 \le k \le n，m=1$。
                      
对于 $70 \%$ 的数据，$1 \le n \le 10^3,1 \le m\le n$。

对于 $100 \%$ 的数据，$1 \le n \le 10^5，0 \le k \le 10^3，1 \le a_i \le n，1\le m \le10^5$，
