# T109577 小R与糖果（数据加强版）

## 题目描述

小R喜欢吃糖果。  
小R有$\text{n}$颗糖果，每颗糖果可以提供一个欢乐值。小R会一种神奇的魔法，每次施展魔法可以使他多得到一颗糖果，这颗糖果的欢乐值是$\text{x+y}$，其中$\text{x}$和$\text{y}$分别是小R已有的两颗糖果的欢乐值。小R在吃掉这些糖果之前想施展k次魔法（必须施展$\text{k}$次）。现在小R想知道他最多能获得的欢乐值的和是多少。

## 输入格式

第一行有两个整数$\text{n，k}$表示初始糖果数量和施展魔法的次数，第二行包含$\text{n}$个整数表示初始时小R的糖果。

## 输出格式

输出一个整数，表示欢乐值和的最大值。答案对$\text{10000007}$取模。

## 输入输出样例 #1

### 输入 #1

```
2 2
3 6
```

### 输出 #1

```
33
```

## 说明/提示

对于$30\%$的数据，有$n\leq10^5，k\leq10^5，\left|a\right|\leq10^5$。  
对于$50\%$的数据，保证数据随机生成。  
对于$100\%$的数据，有$n\leq10^5，k\leq10^9，\left|a\right|\leq10^5$。
