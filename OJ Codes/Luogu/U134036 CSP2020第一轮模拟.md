## 题目描述

请从附件中下载试题，并且完成试题。

请提交一个程序，输入小题的编号，输出一个大写字母作为本题的答案。选择题是 `ABCD`中的一个，判断题正确输出 `T`，错误输出 `F`。

各部分的小题编号如下：

- 单选：1 到 15
- 阅读程序 1：16 到 21
- 阅读程序 2：22 到 27
- 阅读程序 3：28 到 33
- 完善程序 1：34 到 38
- 完善程序 2：39 到 43

## 输入格式

输出一个 1 到 43 的整数，代表小题题号。

## 输出格式

输出对应的小题的答案。

## 说明/提示

参考答题模板（替换掉字符串的内容即可，直接提交该代码将会获得 35 分的好成绩）：

```
#include <string>
#include <iostream>
using namespace std;

int main() {
    string ans =
        "ABCDABCDABCDABC"
        "TFTFAA"
        "TFTFAA"
        "TFTFAA"
        "ABCDA"
        "BCDAB";
    int no;
    cin >> no;
    cout << ans[no - 1];
    return 0;
}
```
