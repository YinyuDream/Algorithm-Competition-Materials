# T157500 Chino 的试卷

## 题目描述

Chino 又在参加萌妹子测试了，今天的考官还是 ygg 和 ggy。（详情参见[Chino的试卷](https://www.luogu.com.cn/problem/P5552)）

今年的卷子上有 $n$ 块积木，第 $i$ 块的高度为 $a_i$，Chino 需要回答 $q$ 道题。每次考官都会询问 Chino 一个区间有多少种不同高度的积木是**可爱的**，一种积木是可爱的当且仅当在选定的区间 $[l_i,r_i]$ 内，与它同样高度的积木正好出现了与它高度相同的次数。

Chino 一眼把这道题秒了便离开了考场，但考卷她忘填了，你能帮 Chino 回答一下吗？

## 输入格式

第一行两个正整数 $n,q$。

第二行共 $n$ 个正整数，第 $i$ 个数表示 $a_i$。

接下来 $q$ 行，每行两个正整数 $l_i,r_i$ 表示一次询问。

## 输出格式

输出 $q$ 行，每行一个非负整数，表示答案。

## 输入输出样例 #1

### 输入 #1

```
7 2 
3 1 2 2 3 4 4
1 5
3 6

```

### 输出 #1

```
2
1

```

## 说明/提示

### 样例解释 #1

第 $1$ 块至第 $5$ 块积木中，高度为 $1$ 的积木有 $1$ 个，高度为 $2$ 的积木有 $2$ 个，所以答案为 $2$。

### 测试点约束

**本题采用捆绑测试。**

对于全部数据，$1\leq n,q \leq 10^6$，$1 \leq a_i \leq n$，$1\le l_i\le r_i\le n$。
