# CF61E Enemy is weak

## 题目描述

罗马人再次发起进攻。这一次，他们的人数远超波斯人，但Shapur已准备好击败他们。他说：“狮子从不惧怕百只绵羊。”

然而，Shapur必须找出罗马军队的弱点才能战胜他们。因此，他给军队分配了一个“弱点值”。

在 Shapur 看来，军队的弱点等于满足下列条件的三元组 $ i,j,k $ 的数量：$ i<j<k $ 并且 $ a_i>a_j>a_k $，其中 $ a_x $ 是站在位置 $ x $ 的人的力量值。罗马军队有一个特殊之处——其中所有人的力量值都是互不相同的。

请帮助 Shapur 计算罗马军队的弱点值。

## 输入格式

输入的第一行包含一个整数 $ n $（$ 3\leq n\leq 10^6 $），表示罗马军队的人数。下一行包含 $ n $ 个互不相同的正整数 $ a_i $（$ 1\leq i\leq n, 1\leq a_i\leq 10^9 $），表示罗马军队中每个人的力量值。

## 输出格式

输出一行，一个整数，即罗马军队的弱点值。

## 输入输出样例 #1

### 输入 #1

```
3
3 2 1

```

### 输出 #1

```
1

```
