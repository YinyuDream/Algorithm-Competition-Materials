## 文件说明

- 每道题通常包含 `.cpp` 代码与同名 `.md` 题解（含题目描述、思路与代码）；
- 竞赛目录内同时收录 `statements.pdf`（题面）与 `tutorial.pdf`（官方题解）；
- 代码以 C++ 为主，另有少量 Python、Pascal。
